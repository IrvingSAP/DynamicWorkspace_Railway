Ayuda — Crear proyecto

Alta de un explorador de estructura: código, nombre visible y visibilidad en la compañía.

← Volver al formulario Listado

Para qué sirve

Crea un proyecto con kind structure_scout: un espacio para explorar una muestra, confirmar campos y guardar un borrador que luego se puede sembrar en FILE GATE o Reverse Studio. No es un validador (GATE), un conciliador (Match) ni un emisor (Reverse).

Quien crea queda como administrador (PA). El alta no sube archivo ni aplica a un destino: el siguiente paso es el hub → módulo Muestra.

Campos de esta pantalla

CampoQué hace
Nombre corto (código) Slug único en la organización (compartido con Worksheets, FilePipe y el resto de apps). Use minúsculas y guiones; no se puede reutilizar un código ya tomado.
Nombre visible Título que verá el equipo en el listado y el hub (p. ej. «CSV proveedor nómina»).
Descripción Opcional. Contexto de la muestra (origen, periodo, qué espera sembrar).
Privado Solo miembros explícitos ven y trabajan el proyecto (según rol).
Público Los UF de la compañía pueden ver el proyecto. Subir muestra, guardar borrador o aplicar siguen exigiendo membresía y rol.

Acciones

  • Crear y continuar — alta el proyecto y abre el hub.
  • Cancelar — vuelve al listado sin guardar.

Qué hacer después

  1. (PA) Invite miembros si otras personas deben explorar o aplicar.
  2. Suba una muestra (CSV, Excel o TXT; no es archivo de producción).
  3. Detecte el patrón → confirme campos → guarde el borrador.
  4. Aplique el borrador a GATE o Reverse (nunca auto-publica allí).

Qué no hace este formulario

  • No sube la muestra ni detecta campos.
  • No valida producción ni publica un contrato GATE.
  • No clona un perfil ya publicado (eso es Importar estructura / Profile Seed).
