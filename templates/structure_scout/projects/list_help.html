Qué es este listado

Es la puerta de entrada a STRUCTURE SCOUT (Explorador). Cada fila es un proyecto que parte de una muestra de archivo, propone campos y guarda un borrador de estructura para sembrarlo en otra app. No valida producción ni publica un contrato GATE. Está aislado de FilePipe, FILE GATE, FILE MATCH y Reverse Studio.

  • Solo se listan proyectos de su compañía (alcance UF).
  • Aparecen los proyectos donde usted es miembro y los públicos de la compañía (aunque no sea miembro).
  • Desde aquí crea un proyecto nuevo o abre el hub de uno existente.

El filtro de Visibilidad en la barra de la tabla permite restringir a públicos o privados. La tabla admite búsqueda y paginación.

Visibilidad y acceso

  • Privado: solo la membresía activa puede ver y trabajar según el rol.
  • Público: UF de la misma compañía pueden ver el proyecto sin ser miembros (consulta). Subir muestra, guardar borrador o aplicar siguen exigiendo el rol adecuado.
  • El creador queda siempre como PA, independientemente de la visibilidad.

Roles (resumen)

RolPermisos principales
PAAdmin: miembros, muestra, detectar, campos, guardar borrador, aplicar a destino.
EDExplorar y guardar borrador; aplicar. No gestiona miembros.
GESubir muestra y explorar (M2–M4). No guarda borrador ni aplica.
COConsulta: hub e historial; sin preview de filas de muestra ni apply.

Los miembros se gestionan dentro de cada proyecto (hub → Miembros, solo PA).

Cómo empezar

  1. Pulse + Nuevo proyecto (nombre, código/slug y visibilidad).
  2. En el hub: Muestra → Detectar → Campos (confirme nombres/tipos; en TXT posicional, inicios y longitudes).
  3. Guarde un borrador de estructura (M5).
  4. Aplique el borrador a un destino FILE GATE o Reverse (nunca auto-publica allí).
  5. Revise el historial. En el destino, revise y publique según esa app.

Regla de producto: Scout no valida archivos de producción. Guía completa: menú STRUCTURE SCOUT → Ayuda.

Qué no es este listado

  • No muestra proyectos de FilePipe, FILE GATE, FILE MATCH ni Reverse Studio.
  • No sube la muestra ni detecta campos (eso ocurre en el hub de cada proyecto).
  • No aplica el borrador ni publica el destino.
  • No sustituye FILE GATE (validar) ni Profile Seed (clonar un contrato ya publicado).
