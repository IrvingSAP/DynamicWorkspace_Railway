← Volver al hub

Qué es este hub

Es el punto de entrada del Explorador. Agrupa la muestra, el patrón detectado, los campos, el borrador de estructura, la siembra a un destino y el historial. No valida un archivo de producción (FILE GATE) ni cruza A vs B (FILE MATCH).

  • Objetivo: descubrir la estructura de un archivo a partir de una muestra y sembrar un borrador en otra app.
  • Strip: estado del draft, nombre de la última muestra y conteo de miembros.
  • Stepper + paneles: cada pastilla del stepper abre el módulo (como en FILE GATE). Los paneles inferiores también llevan al mismo sitio; los siguientes se marcan pendientes hasta confirmar el anterior.
  • Miembros: botón visible solo para el administrador (PA).

Stepper — qué hace cada paso

#PasoPara qué sirveCuándo marca ✓
1 Muestra Sube un CSV, Excel o TXT de ejemplo. No es el archivo de producción. Hay una muestra activa.
2 Detectar Sugiere encoding, tipo, delimitador y encabezado. Usted confirma. Patrón de detección confirmado.
3 Campos Nombres y tipos propuestos. En TXT posicional también Inicio / Fin / Long. (editables). Campos confirmados.
4 Borrador Congela patrón + campos en una versión exportable. No publica destinos. Existe un borrador actual.
5 Aplicar Siembra el borrador en FILE GATE o Reverse (misma compañía). Nunca auto-publica. Hay al menos un apply correcto.
6 Historial Versiones de borrador y aplicaciones a destino. Hay eventos (borrador o apply).

Paneles y acciones

  • Nueva exploración — muestra: cargar o cambiar la muestra activa.
  • Detectar patrón / Campos: proponen; usted confirma. Reabrir para ajustar o re-inferir.
  • Borrador: guardar nueva versión o exportar JSON.
  • Aplicar: sembrar otro destino GATE / Reverse; el destino debe revisarse y publicarse allí.
  • Historial: auditoría; no sustituye el informe de validación GATE.

Orden de trabajo recomendado

  1. Revise miembros (PA) si otras personas deben explorar o aplicar.
  2. Muestra → Detectar → Campos (confirme, no deje todo en automático a ciegas).
  3. Guarde el borrador.
  4. Aplique a un proyecto GATE o Reverse donde tenga rol PA/ED en el destino.
  5. Abra el destino, revise el esquema sembrado y publique allí si corresponde.

Regla de producto: Scout no valida producción y no publica el destino.

Qué no hace este hub

  • No edita el detalle de cada módulo (hay que entrar a Muestra, Detectar, etc.).
  • No publica FILE GATE ni Reverse.
  • No concilia ni transforma archivos.
  • No sustituye Importar estructura desde un contrato ya publicado (Profile Seed).
