STRUCTURE SCOUT · paso 5 · {{ project.slug }}

Ayuda — Aplicar a destino

Siembra el borrador Scout en un perfil de lectura de la suite (GATE, CLEAN, FilePipe, Match A, Reverse, Split/Merge). Nunca publica.

← Volver a aplicar

Para qué sirve

Copia el snapshot del borrador actual (tipo, encoding, campos, posiciones si aplica) al perfil de lectura / entrada de otro proyecto de la misma compañía. El destino queda en edición: hay que revisar el asistente y publicar allí.

No es Profile Seed (clonar un contrato ya publicado) ni FILE GATE (validar producción). El stepper marca Aplicar ✓ cuando hay al menos un apply correcto.

Prerrequisito

Hace falta un borrador Scout guardado. Si no, verá el aviso y un atajo a Borrador. Puede aplicar un draft en «revisión pendiente»; conviene revisar el destino antes de publicar.

Qué ve en esta pantalla

ElementoSignificado
Draft / Estado / Confianza / Campos Versión que se sembrará (vN), si está listo o en revisión, y cuántos campos lleva.
Tipo de proyecto Destinos que aceptan un perfil de lectura: FILE GATE, FILE CLEAN, FilePipe (origen), FILE MATCH (Perfil A), Reverse Studio (entrada) y FILE SPLIT/MERGE. Al cambiar, recarga la lista de proyectos.

Aviso de sobrescritura Si el destino ya tiene campos, aplicar los reemplaza en el borrador del destino (no toca una versión ya publicada hasta que publiquen de nuevo allí).
Aplicar borrador al destino Ejecuta la siembra. Tras el OK, aparece el enlace Abrir destino (esquema GATE o planilla Reverse).
Applies recientes Auditoría corta (fecha, versión, destino, OK/fallido). Ver abre el detalle; el timeline completo está en Historial.

Qué se siembra

  • Tipo de archivo, encoding, fin de línea, delimitador/encabezado según el draft.
  • Campos con nombre interno y tipo. En CSV/Excel, columna o índice. En txt_fixed, Inicio / Fin / Long. confirmados en Campos (no placeholders a ciegas si ya estaban definidos).
  • No copia políticas GATE, reglas Match ni el mapeo Reverse: solo la estructura de lectura.

Después de aplicar

  1. Abra el destino y revise captura (inicio/fin), campos y el resto del asistente.
  2. Publique en esa app cuando el contrato o la planilla estén listos.
  3. Puede aplicar el mismo draft a otro destino (otro GATE, Match, FilePipe, etc.).

Roles

  • En Scout: solo PA / ED aplican.
  • En el destino: también PA / ED (si no, el proyecto no aparece en el combo).
  • GE / CO ven el hub si hay acceso; no siembran.

Qué no hace este módulo

  • No siembra Perfil B de Match (use Copiar A→B o Importar estructura en el destino) ni el mapeo/target de FilePipe.
  • No publica FILE GATE, Reverse, Match ni FilePipe.
  • No valida un archivo de producción ni concilia A vs B.
  • No edita el draft Scout: vuelva a Campos / Borrador si hay que corregir y guardar otra versión.
