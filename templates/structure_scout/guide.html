Cómo funciona STRUCTURE SCOUT

El Explorador de estructura analiza una muestra de archivo y propone un borrador (tipo de archivo, columnas y tipos de contenido). Usted confirma cada paso y luego puede sembrar ese borrador en FILE GATE o Reverse Studio.

No valida archivos de producción (eso es FILE GATE). No clona una definición ya publicada (eso es Importar estructura / PROFILE SEED). Solo ayuda a descubrir la forma del archivo cuando aún no hay contrato.

Ruta rápida

  1. Cree un proyecto Explorador.
  2. Suba una muestra (CSV, Excel o TXT).
  3. Confirme el patrón (tipo, delimitador, header).
  4. Revise nombres y tipos de campos → confirmar.
  5. Guarde el borrador Scout.
  6. Aplíquelo a GATE o Reverse (solo borrador).
  7. En el destino, afine captura u otros detalles del contrato y publique allí.

Ir a proyectos

Los 6 pasos del ciclo

  1. Muestra — Archivo de ejemplo (≤ 10 MB). No es un job de producción.
  2. Detectar — Encoding, tipo (csv / delimitado / Excel / posicional), delimitador, fila de encabezado. Confirme o ajuste.
  3. Campos — Lista de columnas: nombre, tipo, obligatorio, ejemplos. Con txt_fixed también Inicio / Fin / Long. estimados (editables).
  4. Borrador — Congela una versión del snapshot Scout (exportable).
  5. Aplicar — Copia el borrador al proyecto destino (GATE / Reverse). Nunca publica el destino.
  6. Historial — Versiones de borrador y aplicaciones realizadas.

Qué edita en Campos (y qué no)

Delimitados / CSV / Excel: nombre y tipos. Posicional (txt_fixed): además longitudes estimadas.

  • Sí: nombre, tipo (content_type), obligatorio, notas.
  • Sí (si txt_fixed): Inicio / Fin / Longitud estimados; revise solapes antes de confirmar.
  • No (en Scout): políticas GATE, reglas Match, publicación del destino.
  • Las longitudes en Scout son estimación; el contrato definitivo se publica en el destino tras Aplicar.

Scout vs otras apps

  • FILE GATE — Valida archivos contra un contrato ya definido.
  • PROFILE SEED (Importar estructura) — Clona un contrato/perfil publicado a otro borrador.
  • STRUCTURE SCOUT — Parte de una muestra cruda cuando aún no hay definición.

Roles

  • PA / ED — Editan detección y campos, guardan borrador, aplican a destino.
  • GE — Puede subir muestra y confirmar pasos de exploración según el hub; no aplica a destinos.
  • CO — Consulta hubs e historial; sin preview de filas ni ejemplos de celdas.
