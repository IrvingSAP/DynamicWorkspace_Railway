Ayuda — Cargar muestra

El archivo de ejemplo con el que el Explorador propone tipo, encoding y campos. No es validación ni producción.

← Volver a muestra

Para qué sirve

STRUCTURE SCOUT no parte de un contrato publicado: parte de un archivo de ejemplo. Esa muestra alimenta Detectar y Campos. Si la muestra no representa el layout real, el borrador (y lo que se siembre en GATE o Reverse) saldrá desalineado.

Subir aquí no valida el archivo (eso es FILE GATE) ni lo transforma (FilePipe). El stepper marca Muestra ✓ cuando hay al menos una muestra; la exploración usa la última subida.

Qué ve en esta pantalla

ElementoSignificado
Tarjetas Muestras / Límite / Activa Cuántos archivos hay, tope de tamaño (10 MB) y el nombre de la muestra que usa el ciclo.
Arrastrar / Seleccionar archivo Elige el fichero. Aún no se guarda hasta Subir muestra.
Quitar Limpia la selección en el recuadro (no borra una muestra ya guardada).
Subir muestra Persiste el archivo, calcula hash y sugiere tipo / encoding / fin de línea / delimitador.
Muestra activa Última subida: nombre, tamaño, hash corto, fecha, quién subió y sugerencias. CTA a Detectar.
Lista del proyecto Historial de subidas. La marcada activa es la más reciente.
Preview Primeras líneas (hasta 20) para comprobar que eligió el archivo correcto. CO no ve filas.
Eliminar Quita esa muestra del proyecto. Si borra la activa, pasa a ser activa la siguiente más reciente.

Archivos permitidos

ExtensiónUso típico
.csvTabla delimitada por coma (caso frecuente).
.xlsx / .xlsHoja Excel.
.txt / .tsvTexto delimitado (tab, pipe, etc.) o posicional.
  • El archivo no puede estar vacío ni superar 10 MB.
  • Use una muestra realista (cabecera, pie, encoding del proveedor), no un CSV de laboratorio.
  • JSON y XML no entran en la whitelist MVP de Scout.

Siguiente en el ciclo

  1. Detectar patrón — confirma tipo, encoding, delimitador y encabezado (parte de las sugerencias).
  2. Campos — nombres y tipos; en TXT posicional, Inicio / Fin / Long. estimados.
  3. Borrador y luego Aplicar a GATE o Reverse (sin auto-publicar).

Las pastillas del stepper también navegan a esos módulos. Detectar exige una muestra activa.

Roles

  • PA / ED / GE / CG suben, previsualizan y eliminan.
  • CO ve el hub de muestra pero no las filas del preview ni sube archivos.

Qué no hace este módulo

  • No valida el archivo contra un contrato publicado (FILE GATE).
  • No confirma el patrón ni los campos: eso es Detectar y Campos.
  • No publica ni siembra el destino.
