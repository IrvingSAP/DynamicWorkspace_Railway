Ayuda — Editor de mapeo

Guía de la pantalla de trabajo: paneles, tabla, diálogo y preview.

← Volver al editor

Objetivo

En el editor se define de dónde sale el valor de cada campo destino del proyecto {{ project.name }}: copia 1:1, constante, concatenación, trozo de un texto, expresión numérica o un valor generado (secuencia, UUID, etc.). El resultado se guarda en el borrador; no publica la versión FilePipe.

Quién: quien diseña la transformación (editor del proyecto). Ejemplo: el destino numero_factura se arma con el literal FAC- más el campo origen documento (tipo Concatenar).

Cómo ver o cambiar un mapeo ya guardado

Añadir mapeo siempre parte de un formulario vacío (nuevo enlace). Para el correlativo autogenerado (u otro destino ya mapeado) use una de estas vías:

AcciónEfectoEjemplo
Editar (en la fila de Relaciones) Abre el diálogo con tipo Generado, prefijo, inicio, plantilla, etc. ya cargados. Fila destino correlativo · tipo Generado
Clic en la fila Igual que Editar (excepto si pulsa Quitar). —
Clic en el campo del panel Destino Si ya tiene mapeo, abre esa misma condición. Panel derecho → correlativo
Añadir mapeo y elegir el mismo destino Si el destino ya está mapeado, el diálogo pasa a modo edición y carga lo guardado. Campo destino = correlativo

Tras Aplicar, pulse Guardar en la cabecera para persistir el borrador.

Diálogo Mapeo — campos comunes

CampoPara qué sirveEjemplo
Campo destino Campo de salida que recibirá el valor. Un destino suele tener un solo mapeo activo. numero_factura
Tipo de enlace Cómo se obtiene el valor. Al cambiarlo se muestran otros campos. Concatenar
Reglas (casillas) Se aplican después de calcular la fuente: recortar espacios, mayúsculas/minúsculas, formato de fecha, relleno, valor por defecto si vacío. Trim
Formato fecha Visible si marca «Formato fecha». Patrón estilo Python. %Y-%m-%d → 2026-08-14

Tipo Directo (1:1)

CampoPara qué sirveEjemplo
Campo origen Copia el valor tal cual (luego pueden actuar las reglas). origen nombre → destino cliente

Tipo Constante

CampoPara qué sirveEjemplo
Valor constante El destino siempre recibe ese texto, independiente de la fila origen. PE en un campo pais

Tipo Concatenar

Une partes en orden. Cada parte es un literal (texto fijo) o un campo origen.

ControlPara qué sirveEjemplo
+ Literal Añade un texto fijo a la cadena. FAC-
+ Campo Añade el valor de un campo origen. documento

Ejemplo: literal FAC- + campo documento → FAC-8891.

Tipo Dividir (1:N)

Toma un campo origen y extrae una parte. Un mapeo alimenta un destino; para varias partes (nombre y apellido) cree dos mapeos split sobre el mismo origen.

CampoPara qué sirveEjemplo
Campo origen Texto a partir del cual se extrae. nombre_completo = Ana Pérez
Parte · Primera palabra Hasta el primer espacio. Ana
Parte · Resto Todo después de la primera palabra. Pérez
Parte · Por delimitador Parte el texto por un carácter y toma el índice (0 = primera pieza). Delimitador |, índice 1 sobre A|B|C → B
Parte · Substring Recorte por posición (inicio 0) y longitud. Inicio 0, longitud 2 sobre PE123 → PE
Parte · Regex Patrón regular; Grupo 0 es toda la coincidencia, 1 el primer paréntesis. Patrón (\d+), grupo 1 sobre FAC-8891 → 8891

Tipo Expresión

Árbol de operaciones (máximo 5 niveles). La raíz es siempre una expresión. Cada operando puede ser campo origen, literal o otra sub-expresión.

ControlPara qué sirveEjemplo
Operación Sumar, restar, multiplicar, dividir, concatenar o coalesce (primer valor no vacío). Sumar (+) cantidad + recargo
Campo / Literal Operandos. Un literal numérico se escribe como texto, p. ej. 1.18. campo precio × literal 1.18

Para unir textos con formato suele ser más claro el tipo Concatenar que una expresión concat.

Tipo Generado

El valor no viene del archivo origen: lo produce el sistema al ejecutar (o en el preview con las reglas del generador).

En destino TXT de ancho fijo el correlativo debe caber en la ranura del campo. Si correlativo tiene longitud 1, el valor 10 se escribe como 1 (parece un reinicio). Amplíe Inicio/Fin en Destino, paso 4 (p. ej. longitud 4), publique y vuelva a ejecutar.

CampoPara qué sirveEjemplo
Generador Familia: secuencia numérica, con padding, alfanumérica, plantilla, UUID, correlativo por job, fecha/hora de ejecución, número de fila. Secuencia alfanumérica → A1, A2…
Prefijo / Sufijo Texto fijo antes o después del número o secuencia. Prefijo A → A1
Inicio / Paso Primer número y cuánto avanza cada fila o cada job según el alcance. Inicio 1, paso 1
Padding / Carácter pad Rellena a la izquierda hasta N caracteres. Padding 5, carácter 0 → 00001
Plantilla Para generador de plantilla. {seq:5} es la secuencia con 5 dígitos. FAC-{seq:5} → FAC-00001
Alcance Job: un contador por ejecución. Fila: por cada registro. Proyecto: continúa entre ejecuciones del mismo proyecto. Job
Reiniciar por job Si está marcado, el contador vuelve al inicio en cada ejecución. Marcado

Qué no hace esta pantalla

  • No publica la versión FilePipe (eso está en el hub del proyecto, cuando origen, destino, mapeo y reglas estén listos).
  • No define campos nuevos de origen o destino (use los asistentes de origen y destino).
  • Las reglas globales posteriores al mapeo (módulo Reglas) son otro paso; las casillas del diálogo son transformaciones por campo en el propio mapeo.
