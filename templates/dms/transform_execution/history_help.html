Objetivo

Consulta las transformaciones ya ejecutadas del proyecto {{ project.name }} y descarga el archivo destino, el informe y el listado de errores mientras el enlace esté vigente (7 días).

Quién: quien opera o revisa corridas (cualquier miembro del proyecto). Ejemplo: tras pulsar Ejecutar transformación sobre entrada.txt, aquí aparece la fila con salida, filas OK y botones de descarga.

Qué no hace esta pantalla

  • No re-ejecuta el mismo job: para otra corrida suba de nuevo (o use un archivo aún pendiente) y pulse Ejecutar transformación.
  • No publica versiones ni cambia el mapeo; usa la versión publicada que tenía el job al ejecutarse.
  • No sustituye el preview del editor de mapeo (eso es una fila de prueba, no un archivo de producción).
