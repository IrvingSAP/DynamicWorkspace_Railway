Qué no repetimos

En el hub ya está: candado por hash, que aquí no se configura el interruptor, qué estados abren el paso, el flujo en tres pasos y que el vacío no es un error. Siga aquí si un emisor bloquea o si necesita interpretar una tarjeta de vínculo.

Emisores que pueden apuntar a este gate

Un mismo FILE GATE puede recibir varios emisores de la misma compañía. Cada emisor apunta a un gate. Los contratos no se fusionan.

EmisorQué exige el pre-checkDónde se activa
FilePipeValidar el archivo de entrada antes de transformar.Ajustes DMS · Integración FILE GATE
Reverse StudioValidar la planilla antes de generar.Ajustes Reverse
FILE MATCHValidar lado A y/o B antes de conciliar (se puede exigir uno o ambos).Ajustes Match

Matching por hash (casos reales)

SituaciónResultado
Mismo contenido, otro nombre o rutaMismo hash → el pre-check puede pasar.
Edita una celda y vuelve a subirHash distinto → hay que volver a validar en este proyecto.
Valida en FILE GATE pero sube otro archivo al emisorNo hay corrida con ese hash → bloqueo.
Contrato no publicadoEl vínculo se puede crear; el pre-check falla hasta que publique esquema y políticas.
Tipo de archivo del contrato ≠ origen del emisorAviso en ajustes del emisor; no impide vincular, pero suele indicar un gate equivocado.

El pre-check no vuelve a validar el archivo: reutiliza la corrida ya persistida (mismo espíritu que el historial). El hash se calcula al validar aquí y al subir en el emisor.

Por qué bloquea el emisor

Mensaje típicoQué hacer
No hay corrida aceptada con el mismo contenidoValide ese archivo aquí y reintente en el emisor.
La última validación no está aceptadaCorrija el archivo o revise la evidencia. failed / parcial no abren el paso.
Expiró por frescuraVuelva a validar. Un aprobado antiguo fuera de la ventana (p. ej. 7 días) también bloquea. La frescura la define el emisor; no es lo mismo que el TTL de descarga del informe.
El proyecto FILE GATE no tiene contrato publicadoPublique esquema y políticas, luego reintente.
Integración mal configuradaEn el emisor, revise que el proyecto gate exista y el flag esté bien guardado.

Si el pre-check está activo, nadie puede saltarlo (ni el PA). Desactivar el flag solo se hace en ajustes del emisor, no desde esta ayuda.
