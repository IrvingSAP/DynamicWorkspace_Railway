FILE GATE · Módulo 6 · Bridge

Pre-check antes de FilePipe

Los emisores (FilePipe, Reverse Studio o FILE MATCH) pueden exigir que este gate esté en verde antes de transformar, generar o conciliar. FILE GATE no genera el archivo de negocio: solo certifica el contenido.

{% url 'file_gate:bridge_hub_help' project_slug=project.slug as bridge_help_url %} {% include "projects/includes/project_help_link.html" with help_url=bridge_help_url %} ← Proyecto Validar archivo

Qué es

Un candado por contenido

El emisor busca una corrida aceptada de este proyecto con el mismo hash (SHA-256) del archivo. El nombre del fichero no cuenta.

Qué no es

No se configura aquí

El interruptor «Exigir FILE GATE» vive en el proyecto emisor. Desde esta pantalla solo ve quién apunta a este gate y con qué reglas.

Qué desbloquea

Passed (y avisos, si se permite)

Nunca abre el paso un failed, un parcial o un error técnico. Además, la corrida debe estar dentro de la ventana de frescura (p. ej. 7 días).

  1. 1
    Validar aquí Suba el archivo en Validar y obtenga un resultado aceptado.
  2. 2
    Activar en el emisor En FilePipe / Reverse / Match: «Exigir FILE GATE» y elegir este proyecto.
  3. 3
    Mismo archivo, luego emitir Al subir el mismo contenido, el emisor pasa o queda bloqueado con enlace a validar.
