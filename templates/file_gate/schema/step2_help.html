Para qué sirve

Muchos archivos traen cabeceras o líneas de control antes del detalle. Si el inicio está mal, el gate leerá basura como si fueran registros y fallará campos obligatorios o tipos.

ElementoUso típico
Modo de inicioNúmero de línea, tras un patrón, primera línea con datos, etc. (catálogo de límites de captura).
ParámetrosValor del modo: número de línea, texto del patrón, etc.

La unidad es líneas. El fin (paso 3) debe ser coherente con este inicio: el fin no puede quedar “antes” del inicio.
