Ayuda — Campos delimitados (CSV / TXT)

Parte cada línea por un delimitador y valida columnas. Tipo actual: {{ file_type_code|default:"csv" }} (csv o txt_delimited).

← Volver al paso 4

Para qué sirve esta pantalla

El archivo es una tabla en texto. Primero se configuran delimitador, comillas y encabezado; después cada campo del contrato apunta a una columna. El parser usa siempre el índice 0-based; el nombre de columna es referencia cuando hay encabezado.

Parámetros del archivo

Campo en pantallaEfecto en la validación
Delimitador Separa columnas: coma, punto y coma, tabulador o pipe. Debe coincidir con el archivo real; si no, todas las columnas se desalinean.
Carácter de comillas Envuelve valores que contienen el delimitador (normalmente "). Ejemplo: "Calle Sol, 12".
Carácter de escape Opcional. Escapa comillas internas. Vacío si el archivo no lo usa.
Primera fila es encabezado Si está marcado, esa fila no es un registro a validar. Permite etiquetar columnas por nombre.
Fila encabezado Número de fila (1-based) de los títulos. Suele ser 1. Visible con encabezado activo.

Guarde los parámetros con Guardar parámetros antes de cargar muchos campos.

Editor de cada campo

Campo en pantallaEfecto en la validación
Columna del archivo Nombre del encabezado (p. ej. DOC_ID). Referencia; el parseo usa el índice.
Nombre interno Identificador del criterio en el informe.
Índice (0-based) Primera columna = 0, segunda = 1. Obligatorio. En nombre,edad,direccion, edad es índice 1.
Tipo contenido Forma esperada del valor de esa columna.
Campo obligatorio Celda vacía → rechazo.
Formato fecha Visible si el tipo es fecha/datetime.

Ejemplo

nombre,edad,direccion
Beatriz Martinez,19,Calle Parque 282
  • Delimitador: coma · Encabezado: sí · Fila encabezado: 1
  • nombre → índice 0 · edad → 1 · direccion → 2

Relación con captura (pasos 2–3)

El inicio/fin define qué filas se leen. El delimitador e índices definen cómo se parten esas filas. No confunda «fila encabezado = 1» con «inicio de captura = línea 2» si la línea 1 ya es un dato.
