Contrato de informe

Define qué evidencia debe generar cada validación. Este paso no ejecuta el gate ni calcula el umbral de rechazo.

← Volver al paso 6

Qué configura

OpciónEfecto al validar
Informe habilitadoSi está apagado, la corrida puede validar pero no ofrecerá descargas de evidencia.
Resumen / contadoresIncluye métricas (filas leídas, válidas, rechazadas, % rechazo) en el informe.
Detalle por filaIncluye incidencias (línea, campo, código, mensaje) en la evidencia y, si aplica, en CSV.
FormatosJSON y/o CSV disponibles en el informe (Módulo 4), sujetos a TTL y roles.

El umbral que decide passed / failed / partial se define en Políticas. Tras completar este paso, publique el contrato desde el hub para habilitar Validar archivo.

Después de publicar

  • Las nuevas validaciones usan el snapshot publicado (no el borrador en edición).
  • Se crea un nuevo borrador para seguir mejorando el contrato sin afectar corridas en curso.
  • El informe y el certificado de cada job respetan lo congelado aquí.
