FILE GATE · Módulo 1 · {{ project.slug }}

Ayuda — Contrato de validación

Hub del esquema: indicadores, importar estructura, publicar y los 6 pasos del asistente.

← Volver al contrato

Propósito

El contrato describe qué debe cumplir un archivo para considerarse válido en {{ project.name }}. No transforma ni emite un archivo de negocio: congela el criterio que usarán Validar, el informe y el bridge FilePipe.

Edita siempre el borrador. Las corridas usan solo la versión publicada. Tras publicar se abre un borrador nuevo para seguir editando.

Flujo recomendado

  1. Opcional: Importar estructura desde otra app (solo PA/ED) para no rearmar el asistente.
  2. Complete o revise los 6 pasos en el borrador y guarde en cada uno.
  3. Cuando el contrato esté listo, pulse Publicar contrato.
  4. Configure Políticas (umbral passed/failed) y luego Validar archivo.

Asistente (6 pasos)

PasoQué configura
1 · TipoFormato, encoding y fin de línea del archivo a validar.
2 · InicioDesde dónde empiezan los datos útiles (salta cabeceras o títulos).
3 · FinDónde termina la captura (EOF, línea o patrón).
4 · CamposEstructura y criterios de rechazo por campo (obligatorio, tipo, patrón…). También tiene CTA de importar.
5 · ReglasNormalización y exclusiones globales de contenido.
6 · InformeQué debe incluir la evidencia de cada validación (JSON/CSV, resumen, filas).

El umbral que decide passed / failed no vive aquí: se configura en Políticas (Módulo 2).

Roles

RolEn este hub
PA / EDEditan el borrador, importan estructura y publican el contrato.
GE / CGConsultan; pueden validar archivos cuando el contrato está publicado. No editan ni publican el esquema.
COSolo consulta (hub, historial de importaciones en lectura).

Cambiar el tipo de archivo con campos ya definidos puede exigir limpiar o redefinir el paso 4.

Qué no hace este hub

  • No valida un archivo (eso es Validar).
  • No define el umbral de aprobación (eso es Políticas).
  • No es el bridge FILE GATE (pre-check por hash hacia FilePipe).
  • No infiere desde una muestra aquí: Scout se usa como origen del sembrador o desde Explorador con «Aplicar a destino».
  • Importar no publica el contrato ni sustituye Políticas.
