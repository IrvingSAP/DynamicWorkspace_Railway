Para qué sirve esta pantalla

El archivo es un documento JSON. FILE GATE recorre un arreglo de registros y, en cada uno, lee propiedades por ruta con puntos. Cada ruta es un criterio de rechazo, no un mapeo a otro JSON.

Parámetros JSON

Campo en pantallaEfecto en la validación
Ruta de registros
record_path		 Camino hasta el array (u objeto repetido) que representa cada fila. Ejemplos: empleados, data.items. Cada elemento de esa lista se valida por separado.

Guarde con Guardar parámetros tras fijar la ruta de registros.

Editor de cada campo

Campo en pantallaEfecto en la validación
Nombre interno Identificador del criterio en el informe (puede diferir de la clave JSON).
json_path Ruta relativa dentro de cada registro (notación con puntos). Si el registro es {"documento":"A1","persona":{"edad":19}}, use documento o persona.edad.
Tipo contenido Forma esperada del valor en esa ruta.
Campo obligatorio Clave ausente o vacía → rechazo.

Ejemplo

{
  "empleados": [
    { "documento": "A1", "persona": { "edad": 19 } }
  ]
}
  • record_path = empleados
  • Campo documento → json_path documento
  • Campo edad → json_path persona.edad, tipo numérico

Una ruta incorrecta deja el valor vacío y dispara obligatorio o tipo.
