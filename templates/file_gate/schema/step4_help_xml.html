Para qué sirve esta pantalla

El archivo es un documento XML. FILE GATE recorre cada ocurrencia de un elemento repetido (un registro) y lee el texto de etiquetas hijo. Cada etiqueta es un criterio de rechazo, no un mapeo a otro XML.

Parámetros XML

Campo en pantallaEfecto en la validación
Elemento repetido
record_element		 Nombre local del nodo que se repite por registro (sin namespace). Ej.: empleado, item. Cada ocurrencia es una fila a validar.

Guarde con Guardar parámetros tras fijar el elemento repetido.

Editor de cada campo

Campo en pantallaEfecto en la validación
Nombre interno Identificador del criterio en el informe (puede diferir de la etiqueta XML).
element Etiqueta hijo (o ruta simple) dentro del registro de donde se toma el texto. Si el registro es <empleado><documento>A1</documento>…, use documento.
Tipo contenido Forma esperada del texto del elemento.
Campo obligatorio Elemento ausente o vacío → rechazo.

Ejemplo

<nomina>
  <empleado>
    <documento>A1</documento>
    <edad>19</edad>
  </empleado>
</nomina>
  • record_element = empleado
  • Campo documento → element documento
  • Campo edad → element edad, tipo numérico

El nombre local no lleva prefijo de namespace. Una etiqueta distinta deja el valor vacío.
