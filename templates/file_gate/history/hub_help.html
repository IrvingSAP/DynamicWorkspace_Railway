Cómo usar el historial

El historial lista las validaciones finalizadas del proyecto y conserva la trazabilidad aunque la evidencia descargable haya expirado.

← Volver

Qué se lista

Solo corridas finalizadas de este proyecto. Las subidas sin ejecutar y los jobs en cola o en ejecución no aparecen. El historial no recalcula veredictos: muestra el resultado que quedó registrado en la corrida.

TTL y evidencia

Pasados {{ ttl_days }} días desde la finalización, la corrida se marca como expirado. Los metadatos, el resultado y el certificado siguen disponibles; lo que deja de funcionar es la descarga del informe JSON y del CSV de incidencias.
