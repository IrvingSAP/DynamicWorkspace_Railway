Cómo usar Validar

El hub ya dice que se comprueba un archivo contra el contrato publicado y que no se genera salida de negocio. Esta guía cubre el flujo, la subida, los estados y qué hacer después del veredicto.

← Volver a Validar Ver contrato

Qué es esta pantalla

  • Es el punto de partida para ejecutar una corrida: ver la versión publicada, las últimas ejecuciones y entrar a Subir y validar.
  • Valida contra el contrato y la política congelados al publicar, no contra el borrador que esté editando ahora.
  • El detalle de incidencias, el CSV y el certificado viven en Informe / evidencia. El listado filtrable, en Historial.

Flujo

  1. Publique el contrato (esquema + políticas) desde el Resumen del esquema.
  2. En Validar, pulse Subir y validar / Ejecutar ahora.
  3. Arrastre o elija un archivo cuya extensión coincida con el tipo publicado.
  4. La corrida es síncrona: al terminar abre el resultado (veredicto + métricas).
  5. Desde ahí vaya a evidencia, certificado o valide otro archivo. Si un emisor FilePipe exige este gate, use el mismo contenido (mismo hash).

Si el hub está bloqueado

Qué veQué significa
Publique el contrato primeroNo hay versión publicada. Complete esquema y políticas y publique en el hub del contrato.
Su rol permite consultar…Es consultor (CO) o no tiene PA/ED/GE: puede ver resultados, no subir archivos.
Aún no hay validacionesNormal en un proyecto nuevo. No es un error.

Reglas de subida

ReglaDetalle
Un archivo por corridaClic o arrastrar en la zona de carga. No hay lote en este módulo.
ExtensiónDebe coincidir con el tipo del contrato publicado (p. ej. .csv si el contrato es delimitado).
TamañoTope del intake de producción (50 MB en el MVP). El máximo aparece en la tarjeta de política al subir.
Nombre y rutaSe sanitizan. El archivo se lee; no se reescribe ni se transforma.
Tipo de contenidoSi cambia una celda y vuelve a subir, el hash cambia: para el bridge hay que validar de nuevo.

Estados del gate

EstadoSignificado
AprobadoSin errores de contenido. El CSV de incidencias solo trae cabeceras.
Aprobado con advertenciasHay avisos, pero el rechazo quedó dentro del umbral de la política.
RechazadoSe superó el umbral o hubo un error fatal (archivo ilegible o incompatible con el contrato).
ParcialSe alcanzó el máximo de errores antes del fin del archivo; el recorrido quedó incompleto.
Error técnicoFalló la ejecución. Reintente o contacte al administrador.

Una fila con varios errores cuenta una vez en rechazadas. El % de rechazo es rechazadas / leídas.
