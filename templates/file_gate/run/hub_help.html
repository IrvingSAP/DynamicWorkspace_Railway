FILE GATE · Módulo 3 · ayuda

Cómo validar un archivo

Ejecuta un archivo real contra el contrato y la política publicados y obtén el veredicto del gate.

← Volver

Prerrequisito

Debe existir una versión publicada del contrato. Si no la hay, el hub muestra un bloqueo con acceso directo a publicar. Solo los roles PA, ED y GE pueden ejecutar validaciones.

Estados del gate

EstadoSignificado
AprobadoSin errores; el archivo cumple el contrato.
Aprobado con advertenciasDentro del umbral permitido; hay incidencias no bloqueantes.
RechazadoSe superó el umbral de rechazo o hubo un error fatal de contrato.
ParcialSe alcanzó el máximo de errores antes del fin del archivo; recorrido incompleto.

Reglas de subida

  • Solo archivos locales (clic o arrastrar); un job = un archivo.
  • La extensión debe coincidir con el tipo del contrato publicado.
  • Nombres inseguros y rutas se sanitizan; el archivo es de solo lectura.
  • Tamaño máximo alineado al intake de producción (50 MB en el MVP).
