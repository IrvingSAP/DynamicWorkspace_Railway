Ayuda — Publicar versión

Cómo congelar el rail del diseñador en un snapshot inmutable (vN).

← Volver a publicar

Propósito de la página

Publicar copia el borrador del diseñador a una versión inmutable. Los runs usan solo esa versión, no el rail vivo. Tras publicar se abre el número siguiente como borrador: puede seguir diseñando vN+1 sin alterar lo que ya se ejecuta.

Quién: PA y ED publican. GE y CO (y consulta de compañía) ven checklist y snapshot, sin botón de publicar.

Publicar ≠ Activo. Congelar vN no pone el pipeline en operación. El PA marca Activo en el hub; sin eso, Ejecutar permanece bloqueado.

Cabecera y franja

ElementoQué es
Título Publicar vN Número que se asignará si el checklist pasa. Irreversible para ese número.
Publicará / Activa hoy Próxima versión vs. snapshot que usan los runs ahora (o «ninguna»).
Ayuda (icono) Abre esta página.
← Hub Vuelve al centro de control.
Publicar vN Solo PA/ED. Si el checklist falla, el botón no publica: muestra alerta con el motivo (p. ej. No puede publicar. Pasos no completados: Diseñar pasos.).

Checklist P1–P5

Verde = cumple. Rojo = bloquea. Si Diseñar pasos no está completo, P2–P5 aparecen como pendientes de diseñar.

CódigoQué comprueba
P1 Hay al menos un paso guardado en el diseñador.
P2 Cada kind está en el catálogo, habilitado y alineado con el tipo del proyecto.
P3 Cada proyecto existe, es de la compañía y tiene versión publicada vigente.
P4 Handoff: primer paso pipeline_input, resto previous; el anterior debe producir archivo; Split (N salidas) no alimenta un paso de 1 archivo; foreach no se publica. File Match no exige dos archivos aquí: usa el archivo previo como entrada A.
P5 Quien publica puede usar cada proyecto del rail (público o membresía).

Snapshot a congelar

Vista previa del rail que quedará en vN (kind → slug de proyecto). Si está vacío, complete y guarde Diseñar pasos. No es editable aquí: para cambiar el orden vuelva al diseñador y publique de nuevo.

Versiones publicadas

Historial de snapshots (número, fecha, quién publicó). Las versiones anteriores no se reescriben; el run usa la marcada como activa en la franja («Activa hoy»).
