Ayuda — Diseñador de pasos

Cómo armar el borrador del rail: tipo del catálogo, proyecto activo, orden y handoff.

← Volver al diseñador

Propósito de la página

Edita el borrador de la siguiente versión del pipeline {{ pipeline.name }}. Cada paso es un kind habilitado en el catálogo más un proyecto activo de esa app (misma compañía). File Pipeline no elige v2/v5 de cada app: al ejecutar usará la versión publicada vigente de ese proyecto.

Quién: PA y ED editan y guardan. GE y CO (y consulta de compañía) solo ven el rail. Guardar con al menos un paso válido marca «Diseñar pasos» completo en el hub; sin eso, publicar se rechaza.

Cabecera y acciones

ElementoQué es
Ayuda (icono) Abre esta página.
← Hub Vuelve al centro de control del pipeline.
Guardar borrador Persiste el rail. Visible solo si puede editar (PA o ED). Un rail vacío se puede guardar, pero no completa el módulo 1 del hub.

Agregar paso

Campo / acciónFunciónValores
Tipo (catálogo) Kind opt-in. Al cambiarlo, se recarga la lista de proyectos. Solo kinds con pipeline habilitado y no deshabilitados.
Proyecto activo Destino que ejecutará ese paso. Activos del kind, públicos o a los que está autorizado, con versión publicada vigente. Si no hay: Sin proyectos activos autorizados.
+ Añadir al rail Inserta el paso al final. No guarda en servidor hasta pulsar Guardar borrador. —

Rail del borrador

Lista ordenada (nodos numerados), no un canvas. Cada tarjeta muestra kind, slug del proyecto, origen de entrada y política de error.

Dato / acciónSignificado
Número del nodo Orden de ejecución (1, 2, 3…).
input: pipeline_input Solo el primer paso: toma el archivo (o lote) que el usuario entrega al ejecutar.
input: previous Pasos siguientes: usan la salida del paso anterior.
on_error: stop Si el runner falla, el pipeline se detiene (único valor en este MVP).
Subir / Bajar Reordena. Al reordenar, el handoff se recalcula (el nuevo primero siempre es pipeline_input).
Quitar Elimina el paso del rail en pantalla (confirme con Guardar borrador).

Qué valida y qué no

SituaciónEfecto
Kind fuera de catálogo o deshabilitado No se ofrece en el picker; no se guarda.
Proyecto inactivo, otra compañía o sin versión vigente No aparece en el picker; el guardado lo rechaza.
0 pasos al guardar Permitido como incompleto; el hub no marca «Diseñar pasos».
Handoff dudoso (p. ej. arity de Match) Aviso suave aquí; el bloqueo duro, si aplica, es al publicar.

Publicar congela un snapshot (vN). Seguir editando el diseñador prepara vN+1; el run sigue usando la última versión publicada, no este borrador, hasta que publique de nuevo.
