Cómo funciona File Pipeline

File Pipeline orquesta un archivo por varias apps (Clean, Gate, Pipe, …) y reporta OK/Error por paso.

No es un limpiador, validador ni mapeador: invoca esas apps con su versión publicada.

Ruta rápida

  1. Cree un pipeline (queda PA, estado En proceso).
  2. Invite miembros si es privado.
  3. Diseñe el rail de pasos (módulo 2).
  4. Publique una versión (módulo 3).
  5. Ejecute, consulte el historial y el dashboard de corridas.
