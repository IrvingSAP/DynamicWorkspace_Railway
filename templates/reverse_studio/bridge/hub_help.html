Ayuda — Integración FILE GATE

Pre-check opcional de la planilla antes de emitir el archivo de envío.

← Volver a integración

Propósito

Exige una corrida FILE GATE aceptada (mismo content hash) antes de generar. No fusiona contratos ni sustituye al validador.

Flujo recomendado

PasoDónde
1. Validar planillaFILE GATE → Validar
2. Gate en verdepassed / passed_with_warnings
3. Generar layoutReverse Studio → Generar

Roles

RolPuede
PA / EDConfigurar bridge
PA / ED / GEGenerar si el pre-check pasa
CualquieraNo saltar el check en MVP

Qué no hace

  • No genera el archivo de envío desde FILE GATE.
  • No sincroniza el contrato de entrada con el esquema FG.
  • No es obligatorio: con el flag apagado, Generar funciona como M5.
