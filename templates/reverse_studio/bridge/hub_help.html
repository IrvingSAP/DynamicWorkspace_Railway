Ayuda — Integración FILE GATE

Pre-check opcional: la planilla debe haber pasado FILE GATE (mismo contenido) antes de generar el archivo de envío.

← Volver a integración Ir a generar

Qué es

Reverse emite el layout; FILE GATE valida la planilla. El bridge no fusiona contratos ni vuelve a validar aquí: busca una corrida FILE GATE aceptada con el mismo content_hash que el archivo que sube en Generar.

Flujo recomendado

  1. Publique el contrato FILE GATE (esquema + políticas) del proyecto vinculado.
  2. Valide esa planilla en FILE GATE → Validar (resultado accepted según el umbral).
  3. En Reverse, active el flag, elija el proyecto GATE, acepte y frescura, y guarde.
  4. En Generar, suba el mismo contenido. Si el pre-check pasa, se emite el archivo de envío.

Qué no es

  • No genera el archivo de envío desde FILE GATE.
  • No sincroniza el contrato de entrada Reverse con el esquema GATE (eso no es el bridge).
  • No es Importar estructura (PROFILE SEED): el seed clona campos al borrador; el bridge exige una corrida sobre un archivo.
  • No es obligatorio: con el interruptor apagado, Generar (M5) corre sin pre-check.
