Proyectos de emisión de su compañía: qué ve, qué significan las columnas y cómo empezar.

← Volver al listado Nuevo proyecto

Qué es

Puerta de entrada a Reverse Studio (emisor). Cada fila es un proyecto reverse: planilla amigable (CSV / Excel / delimitado) → layout de envío (TXT posicional / JSON / XML). No mezcla FilePipe, FILE GATE ni FILE MATCH.

Flujo recomendado

  1. Pulse + Nuevo proyecto (solo UF).
  2. Abra el hub: entrada → salida → mapeo → publique.
  3. Genere subiendo la planilla; consulte historial y descargas.

Qué no es

  • No lista proyectos de otras apps.
  • No edita contratos ni sube planillas (eso es el hub).
  • No genera el archivo de envío.
