Qué es este listado

Es la puerta de entrada a Reverse Studio (Emisor). Cada fila es un proyecto con kind reverse: convierte una planilla amigable (CSV / Excel / delimitado) en el layout de envío (TXT posicional / JSON / XML). Está aislado de FilePipe, FILE GATE y FILE MATCH.

  • Solo se listan proyectos de su compañía (alcance UF).
  • Aparecen los proyectos donde usted es miembro y los públicos de la compañía (aunque no sea miembro).
  • Desde aquí crea un proyecto nuevo o abre el hub de uno existente.

El filtro de Visibilidad en la barra de la tabla permite restringir a públicos o privados.

Visibilidad y acceso

  • Privado: solo membresía activa puede ver y trabajar según el rol.
  • Público: UF de la misma compañía pueden ver el proyecto sin ser miembros. Editar, publicar o generar siguen exigiendo el rol adecuado.
  • El creador queda siempre como PA, independientemente de la visibilidad.

Roles (resumen)

RolPermisos principales
PAAdmin: miembros, editar definición, publicar, generar, bridge.
EDEditar entrada / salida / mapeo; publicar; generar.
GEGenerar y descargar archivo de envío (sin editar definición).
COConsulta: ver hub e historial; sin editar ni generar datos de negocio.

Los miembros se gestionan dentro de cada proyecto (hub → Miembros, solo PA).

Cómo empezar

  1. Pulse + Nuevo proyecto (nombre, código/slug y visibilidad).
  2. En el hub, complete Entrada → Salida → Mapeo.
  3. Publique la definición.
  4. Genere subiendo la planilla; revise historial y descargas.

Regla de producto: no se genera sin versión publicada. FILE GATE es opcional (pre-check de la planilla).

Qué no es este listado

  • No muestra proyectos de FilePipe, FILE GATE ni FILE MATCH.
  • No edita contratos ni mapeo (eso ocurre en el hub de cada proyecto).
  • No genera archivos de envío ni sube planillas.
