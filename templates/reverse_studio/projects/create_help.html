Nombre, código (slug) y visibilidad del emisor. Quién crea queda como administrador (PA).

Qué crea este formulario

Un proyecto Reverse Studio (kind reverse) en su compañía: listo para definir planilla → layout → mapeo → publicar → generar. No crea la definición de campos ni genera archivos todavía.

Campos

CampoDetalle
Nombre corto (código) Slug único por compañía, compartido con Worksheets / FilePipe / otras apps. Use minúsculas y guiones (p. ej. emision-pagos-banco).
Nombre visible Título que verá el equipo en listados y hub.
Descripción Opcional: contexto de negocio (banco, ciclo mensual, layout destino…).
Visibilidad Privado o Público (ver abajo).

Visibilidad

OpciónEfecto
Privado Solo usuarios que agregue en Miembros ven y trabajan el proyecto.
Público Cualquier UF de la compañía puede ver el proyecto. Editar, publicar o generar siguen exigiendo rol (ED / GE / PA).

Después de crear

  1. Queda como PA automáticamente.
  2. Si el proyecto es privado, invite miembros (hub → Miembros).
  3. Configure el contrato de entrada (asistente de 6 pasos).
  4. Siga con salida → mapeo → publicar → generar.

Sin versión publicada no se puede generar el archivo de envío.

Qué no hace esta pantalla

  • No define campos de planilla ni layout.
  • No publica ni genera archivos.
  • No crea proyectos FilePipe, FILE GATE ni FILE MATCH (use el menú de cada app).
