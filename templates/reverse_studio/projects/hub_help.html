Ayuda — Hub del proyecto

Tablero del ciclo: planilla → layout → mapeo → publicar → generar → historial. FILE GATE es un extra opcional.

← Volver al hub Ir a entrada

Qué es

Punto de entrada del emisor. Convierte una planilla amigable en el layout del banco/ERP. No es FilePipe (ETL) ni FILE GATE (solo valida; no escribe el archivo de negocio).

Flujo recomendado

  1. Complete entrada (6 pasos) y salida (6 pasos).
  2. Enlace campos en mapeo (reglas opcionales).
  3. Publique. Sin versión activa, Generar está deshabilitado en el stepper.
  4. Opcional: active Integración FILE GATE si la planilla debe haber pasado el gate.
  5. Genere y consulte el historial.
