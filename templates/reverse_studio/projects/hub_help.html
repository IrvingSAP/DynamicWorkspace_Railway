Qué es este hub

Es el punto de entrada del proyecto Reverse Studio (emisor). Agrupa el contrato de la planilla, el layout de envío, el mapeo, la versión publicada, las generaciones y el historial. No es FilePipe (hub ETL amplio) ni FILE GATE (solo valida; no escribe el archivo de negocio).

  • Objetivo: convertir una planilla amigable (CSV / Excel / delimitado) en el layout que espera el banco, ERP u otro destino (TXT posicional / JSON / XML).
  • Strip superior: versión borrador, versión activa publicada y conteo de miembros.
  • Stepper + paneles: avance del ciclo y accesos a cada módulo.
  • Miembros: botón visible solo para el administrador (PA).

Stepper — qué hace cada paso

#PasoPara qué sirveCuándo se activa
1 Planilla / entrada Define cómo viene la planilla de negocio (tipo, encoding, campos, reglas de contenido). Desde el inicio; asistente de 6 pasos.
2 Salida Define el layout de envío (posicional / JSON / XML) y sus campos. Tras completar la entrada (recomendado).
3 Mapeo Enlaza campos planilla → layout y aplica reglas (trim, upper, constantes, etc.). Tras completar la salida (recomendado).
4 Publicar Congela entrada + salida + mapeo en una versión activa. Sin publicar no se puede generar. Cuando el borrador está listo; queda marcado si ya hay publicada.
5 Generar Sube la planilla y emite el archivo de envío con la definición publicada. Solo con versión activa; si no, el paso aparece deshabilitado.
6 Historial Auditoría de emisiones, descargas y TTL. Siempre accesible; vacío hasta la primera generación.

Roles (resumen)

RolEn este hub
PA Administra el proyecto y miembros; edita definición; puede publicar y generar según permisos.
ED Edita entrada, salida y mapeo; puede publicar.
GE Ejecuta generaciones sobre la versión publicada; no diseña el contrato.
CO Consulta metadatos / historial acotado; no descarga celdas ni edita.

Reglas útiles

  • Se edita en borrador; solo la versión publicada se usa al generar.
  • Completar entrada, salida o mapeo por separado no habilita Generar: hace falta publicar.
  • Una corrida de generación lee la planilla y escribe el archivo de salida; no altera la definición.
  • FILE GATE es opcional: valida la planilla; Reverse Studio es quien emite el layout.
