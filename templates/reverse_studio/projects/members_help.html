Ayuda — Miembros y permisos

Quién puede ver y trabajar en este emisor y qué hace cada rol.

← Volver a miembros

Propósito

Solo el administrador (PA) gestiona miembros. Se invitan usuarios UF de la compañía {% if company %}{{ company.name_short }}{% else %}actual{% endif %}. La membresía es la misma infraestructura compartida con Worksheets / FilePipe (ProjectMembership); el rol define qué puede hacer en Reverse Studio.

  • Proyecto privado: sin membresía activa no hay acceso.
  • Proyecto público: la compañía puede verlo; para editar o generar hace falta rol (invitación).
  • El creador / propietario permanece como PA y no se revoca desde esta pantalla.

Roles en Reverse Studio

CódigoNombrePermisos principales
PA Admin Miembros, editar definición (entrada/salida/mapeo), publicar, generar, bridge FILE GATE.
ED Editor Editar entrada / salida / mapeo y publicar; generar. Sin gestionar miembros.
GE Generar Generar y descargar el archivo de envío sobre la versión publicada. Sin editar definición.
CO Consulta Ver proyecto e historial (metadatos). Sin editar, publicar ni generar datos de negocio.

Acciones de la pantalla

AcciónQué hace
Agregar / AutorizarCrea o reactiva membresía con el rol elegido (solo UF de la compañía).
Cambiar rolActualiza el permiso (no aplica al propietario).
RevocarDesactiva el acceso (con confirmación). El usuario deja de operar el proyecto.
ReactivarVuelve a activar un miembro inactivo.
PropietarioEl dueño no se revoca ni pierde PA desde esta pantalla.

Buenas prácticas

  • En proyectos privados, invite al menos un ED o GE antes de operar en producción.
  • Use GE para quien solo emite archivos cada ciclo, sin tocar el contrato.
  • Use CO para auditoría o seguimiento sin riesgo de editar o generar.
  • Generar siempre usa la versión publicada; el rol no sustituye publicar.
