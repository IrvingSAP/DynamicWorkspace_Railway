Ayuda — Campos del layout

Cada campo del archivo de envío. La UI cambia según posicional, JSON o XML.

← Volver al paso 4

Qué decide este paso

Declara los campos destino que el receptor espera. El mapeo (M3) enlazará campos de la planilla → estos nombres. Entrada usa content_type; salida usa data_type.

Según tipo

TipoQué defines
txt_fixed Nombre, start/end (o longitud), alineación, relleno, obligatorio.
json Nombre, path/clave en el JSON, tipo de dato, obligatorio.
xml Nombre, path/elemento, tipo de dato, obligatorio.

Acciones

AcciónEfecto
Cargar desde entrada Siembra nombres/labels/tipos desde la planilla. Debe existir contrato de entrada con campos. Usted completa posiciones o paths.
+ Agregar campo Nueva fila en el layout.
Guardar / editar Persiste el borrador. Nombres únicos; en posicional, rangos sin solape.

Notas

  • El nombre interno será la clave en el mapeo: manténgalo estable.
  • Al publicar (M4) se exige al menos un campo destino (OUT10).
  • Cambiar el tipo de layout (paso 1) puede invalidar estos campos (OUT4).
