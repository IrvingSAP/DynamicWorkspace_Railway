Ayuda — Campos del layout (JSON)

Cada campo se escribe en un path relativo al registro (notación con puntos). No hay inicio/fin de columna.

← Volver al paso 4 Ir al paso 5

Qué es

El tipo del paso 1 es JSON. La raíz, records_path y pretty print se configuran en el paso 3. Aquí solo declara claves dentro de cada registro.

Flujo recomendado

  1. Revise en el paso 3 si los registros están en la raíz o en una ruta (data.items).
  2. Opcional: Cargar desde entrada; luego ajuste cada path al contrato JSON del receptor.
  3. Use puntos para anidar: cliente.documento.
  4. El nombre interno puede ser distinto del último segmento del path.

Campos de esta pantalla

ControlSignificado
Nombre Clave para el mapeo. Obligatorio, único.
path Ruta relativa al registro. Obligatorio. Ejemplo: documento o pago.monto.
Etiqueta / Order / Tipo / Oblig. Metadatos del layout. El JSON generado usa el path, no la etiqueta.

Relación con el paso 3

Si la raíz es un array, cada objeto del array recibe estos paths. Si usó records_path, los paths son relativos a ese nodo, no al documento entero.

Si algo no encaja

SituaciónQué hacer
Claves en el lugar incorrectoRevise raíz / records_path (paso 3) y el path de cada campo.
Path vacíoEl editor exige path. No use posiciones de TXT aquí.
Cargar desde entrada deja paths = nombreEsperado: complete el path real del proveedor.
