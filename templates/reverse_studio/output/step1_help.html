Ayuda — Tipo de layout de envío

Formato rígido que exige el receptor. Condiciona estructura (paso 3), campos (paso 4) y serialización.

← Volver al paso 1 Ir al paso 2

Qué es

Elige el tipo de archivo de salida. No es la planilla de negocio (entrada) ni genera el archivo. El diferenciador de Reverse es planilla fácil → layout rígido.

Flujo recomendado

  1. Elija lo que el banco/ERP ya exige (casi siempre TXT posicional).
  2. Pulse Guardar borrador o Siguiente.
  3. Si ya había campos y cambia el tipo, confirme: puede vaciar el paso 4.

Campos de esta pantalla

ControlSignificado
TXT posicional (txt_fixed) Caso estrella: longitud de registro, posiciones, pad. Bancos y legacy.
JSON (json) Batch / API. Raíz array u objeto en el paso 3; paths en el paso 4.
XML (xml) Elemento raíz y por registro en el paso 3; tags/paths en el paso 4.
Guardar / Siguiente Persiste en el borrador. ← Anterior vuelve al hub de salida.

Si cambia el tipo

SituaciónResultado
Aún no hay camposPuede cambiar de tipo sin impacto.
Ya hay camposConfirmación: las posiciones/paths del otro formato no sirven.
CSV / Excel / delimitadoNo son salida Reverse. La planilla ya es entrada; emítalos en FilePipe si hace falta.
