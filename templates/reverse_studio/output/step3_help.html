Ayuda — Estructura del archivo

Parámetros de layout según el tipo del paso 1 (posicional / JSON / XML).

← Volver al paso 3

Qué decide este paso

La estructura del archivo de envío: longitud de registro, raíz JSON/XML, BOM, patrón de nombre al descargar. No define aún cada campo (paso 4).

Según tipo (MVP Reverse)

TipoQué suele configurarse
txt_fixed Longitud de registro, nueva línea al final de cada registro, patrón de nombre, BOM opcional.
json Tipo de raíz / envoltura del documento, patrón de nombre.
xml Elemento raíz, elemento de registro, patrón de nombre.

Patrón de nombre

output_filename_pattern define cómo se llama el archivo al descargar tras generar (M5), p. ej. con fecha. No afecta el contenido de las filas.

Cabeceras

  • En salida Reverse no hay “incluir fila de encabezado” de planilla: CSV/Excel no son tipos de emisión MVP.
  • La cabecera de la entrada sirve para leer columnas; aquí el receptor espera posiciones, paths o tags.
