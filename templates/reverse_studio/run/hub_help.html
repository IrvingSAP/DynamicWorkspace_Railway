Ayuda — Generar archivo de envío

Sube la planilla, emite el layout con la definición publicada y descarga el resultado. No edita ni publica el contrato.

← Volver a generar Ir al historial

Qué es

Flujo de emisión: planilla de negocio → parse → mapeo → reglas → serialización → archivo de envío (banco / ERP). Usa solo la versión publicada activa (la que muestra la franja del proyecto). El job no cambia esa versión.

Flujo recomendado

  1. Publique la definición (Módulo 4). Sin publicada, esta pantalla pide ir a publicar.
  2. Suba la planilla con la extensión del contrato de entrada (csv / xlsx / delimitado).
  3. Opcional: Vista previa (dry run de filas, no cierra el job).
  4. Pulse Generar archivo y confirme. Recibirá resumen OK / rechazadas.
  5. Descargue envío, informe y errores mientras el TTL esté vigente. El listado filtrable es Historial (M6).

Integración FILE GATE (opcional)

Si el bridge está activo, aparece un sello y una columna extra. Antes de generar se exige una corrida FILE GATE aceptada con el mismo content_hash que la planilla. El botón queda deshabilitado si está bloqueado; use Validar en FILE GATE, evidencia o certificado según los enlaces de la fila.

Qué no es

  • No edita entrada, salida, mapeo ni reglas (use M1–M3 sobre el borrador y vuelva a publicar).
  • No publica la definición (Módulo 4).
  • No sustituye al historial filtrable (Módulo 6) ni configura el bridge (Módulo 7).
  • No elige carpeta en el servidor ni programa jobs. Un job no modifica la versión publicada.
