Ayuda — Generar archivo de envío

Suba la planilla, genere el layout publicado y descargue el archivo.

← Volver a generar

Propósito

Emite el archivo de envío (banco / ERP) a partir de una planilla de negocio, usando solo la definición publicada. No edita el contrato ni publica versiones.

Prerrequisitos

RequisitoDónde se resuelve
Definición publicadaMódulo 4 — Publicar.
Planilla de producciónEsta pantalla (sección subir).
Permiso de generaciónRoles PA / ED / GE.

Acciones principales

AcciónEfecto
Subir planillaCrea un job listo (estado uploaded) contra la versión publicada.
Vista previaDry run de N filas para validar sin cerrar el job completo.
Generar archivoJob completo: layout + informe + errores si aplica.
DescargasEnlaces firmados (TTL típico 7 días). Rol CO no descarga datos de negocio.
RecientesListado mínimo; historial filtrable = Módulo 6.

Qué no hace este módulo

  • No edita entrada, salida ni mapeo.
  • No exige pre-check FILE GATE (Módulo 7 / Fase 2).
  • No sustituye al historial avanzado.
