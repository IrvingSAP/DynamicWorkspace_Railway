Ayuda — Editor de reglas

Pipeline ordenado por campo del layout. Vacío = se escribe el valor del mapeo sin transformar.

← Volver al editor Ir al hub de reglas

Qué es

Aplica operaciones después de resolver el mapeo (directo, constante, concat, generado…) y antes de serializar el layout. El orden importa: de arriba abajo. Máximo 20 pasos por campo.

Flujo recomendado

  1. Elija un campo del layout en la lista izquierda.
  2. Añada pasos o aplique una plantilla (luego ajústela).
  3. Reordene (p. ej. trim antes de pad).
  4. Pruebe con un literal o con la 1ª fila muestra (no ejecuta un job).
  5. Pulse Guardar (el preview no persiste solo).

Controles de esta pantalla

ControlSignificado
Lista de campos Solo destinos ya mapeados. El pipeline se edita de uno en uno.
Plantilla / Aplicar plantilla Carga una secuencia típica sobre el campo activo. Reemplaza los pasos actuales.
+ Paso Añade una operación al final. Elija el op y complete parámetros.
Subir / bajar / quitar Reordena o elimina un paso. Trim → pad es el orden habitual en posicional.
Sin reglas Estado válido: el valor del mapeo pasa intacto a la escritura.
Preview · Valor de prueba Literal que recorre el pipeline del campo activo.
Usar 1ª fila muestra Si hay archivo de muestra, toma el valor post-mapeo de la primera fila. No es Generar.
Guardar Persiste todos los pipelines en el borrador de la versión.

Operaciones

OperaciónEfecto / parámetros
trim / ltrim / rtrimQuita espacios (ambos lados o uno).
upper / lowerMayúsculas o minúsculas.
date_formatSalida format (p. ej. %Y-%m-%d) y input_formats de entrada, separados por coma.
pad_left / pad_rightRellena con char hasta length (típico en TXT posicional).
default_if_emptySi queda vacío, escribe value.
number_formatMontos: decimales, separador de miles y decimal.
number_integerEntero (edad, cantidad). Sin parte decimal.
replace / replace_mapSustituir texto o mapa de códigos (match exacto del valor completo).
substring / regex_extractRecortar o extraer un grupo de un patrón.
coalesce / boolean_mapValor alternativo si vacío; o sí/no hacia textos de salida.

No confundir

Esto (reglas M3)No es…
Transforma el valor después del mapeo Reglas de contenido de entrada (paso 5): limpian al leer la planilla
Por campo del layout Serialización de salida (paso 5): padding/truncate global al escribir
Preview local Un job de Generar ni el historial

Si algo no encaja

SituaciónQué hacer
El pad se come espacios útilesPonga trim antes de pad.
Fecha mal formateadaRevise input_formats frente al valor post-mapeo (no el de Excel crudo si ya hubo parse).
Op desconocida / paramsEl guardado rechaza el paso. Complete longitud, mapa, regex, etc.
Preview distinto a GenerarEl job usa la versión publicada y el archivo real, no solo el literal de prueba.

Qué no es

  • No crea ni borra campos de entrada o salida.
  • No sustituye un mapeo constant / generated (eso es el editor de enlaces).
  • No publica la definición ni emite el archivo de envío.
