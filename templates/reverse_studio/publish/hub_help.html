Ayuda — Publicar definición

Congela el borrador (entrada + salida + mapeo + reglas) en una versión activa. No genera el archivo de envío.

← Volver a publicar Ir a generar

Qué es

Convierte el diseño en una definición publicada contra la que se generan archivos (M5). No hay publicación parcial de planilla o layout: se congela todo junto. Sin publicar no hay emisión.

Flujo recomendado

  1. Deje el checklist en Listo (tarjetas enlazan a cada módulo).
  2. Pulse Publicar vN y confirme el diálogo.
  3. vN queda activa y se abre el borrador vN+1 (copia editable).
  4. Use Continuar a generar para subir la planilla. Si ajusta el diseño, vuelva a publicar.

Tras publicar verá el mensaje de vN activa y nuevo borrador. Republicar sustituye la versión que usa Generar; las anteriores quedan históricas.

Qué no es

  • No edita campos ni mapeos (use M1–M3 sobre el borrador).
  • No sube la planilla ni escribe el archivo de envío (Generar).
  • No es publicar solo el esquema FILE GATE. Publicar no ejecuta un job.
