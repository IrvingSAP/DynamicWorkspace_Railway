Ayuda — Publicar definición

Congela el borrador (entrada + salida + mapeo + reglas) en una versión activa. No genera el archivo de envío.

← Volver a publicar

Qué es este módulo

Es el paso que convierte el trabajo de diseño en una definición publicada contra la cual se generarán archivos (Módulo 5). Sin publicar, no hay emisión (RS2 / MAP7 / OUT7). No es “publicar solo la planilla” ni “publicar solo el layout”: se congela todo junto (PUB2).

Borrador vs versión activa

ConceptoDetalle
Borrador Versión editable donde trabaja en M1–M3. Se publica con el botón Publicar vN.
Versión activa Última definición published. Las generaciones usan solo esta.
Tras publicar vN queda activa y se abre un nuevo borrador vN+1 (copia editable) (PUB4).

Checklist antes de publicar

El hub muestra ítems (entrada, salida, mapeo, reglas…). Cada tarjeta indica Listo o Pendiente y enlaza al módulo correspondiente. El botón publicar permanece deshabilitado hasta que no haya bloqueos; el servidor también valida en modo strict (PUB5).

  • Entrada: tipo whitelist, campos, pasos del asistente.
  • Salida: layout whitelist (posicional / JSON / XML), campos, encoding explícito.
  • Mapeo: obligatorios del layout cubiertos.
  • Reglas: opcionales; no bloquean si están vacías, pero se incluyen en el snapshot si existen.

Qué se congela

IncluidoNotas
Contrato de entradaPlanilla csv / xlsx / delimitado + captura + campos + reglas de lectura.
Contrato de salidaLayout + campos + serialización + validación al escribir.
Mapeo + reglasEnlaces planilla → layout y transform_pipeline.

Quién puede publicar

  • Solo PA / ED (PUB1).
  • GE genera contra la versión activa; no publica.
  • CO consulta; no publica ni genera datos de negocio.

Después de publicar

  1. Confirme el diálogo; verá el mensaje de éxito con vN publicada y nuevo borrador.
  2. Use Continuar a generar (Módulo 5) para subir la planilla y emitir el archivo.
  3. Si necesita ajustes: edite el nuevo borrador → vuelva a publicar (la nueva activa sustituye la anterior para generar).

Qué no hace esta pantalla

  • No edita campos ni mapeos (use M1–M3).
  • No sube planillas ni escribe el archivo de envío (eso es Generar).
  • Publicar no ejecuta un job: solo habilita la generación (PUB9).
