Ayuda — Campos de la planilla

Define qué columnas leer y con qué nombre interno se usarán en mapeo, reglas y generación.

← Volver al paso 4

Qué decide este paso

Declara los campos de la planilla. La UI depende del tipo del paso 1 (Excel → hoja + columna; CSV/delimitado → índice / encabezado). No es el layout de envío (Módulo 2).

Nombre interno ≠ encabezado del Excel

Son dos datos distintos. El nombre interno no tiene que ser igual al texto de la fila de encabezados. Lo que debe apuntar bien a la celda es la propiedad Columna.

PropiedadQué es¿Debe coincidir con el Excel?
Nombre interno Clave estable del contrato (tipo_documento, monto). Se usa en mapeo (M3), reglas y salida. No. Puede ser distinto del encabezado.
Columna Indica de dónde leer en la planilla. Sí (letra Excel o texto del encabezado; ver abajo).

Ejemplo válido: encabezado Tipo Documento, columna D o Tipo Documento, nombre interno tipo_documento.

Excel — cómo rellenar «Columna»

FormaEjemploNotas
Letra de columna A, B, D Independiente del texto del encabezado. Recomendada si los títulos cambian entre archivos.
Nombre de encabezado Tipo Documento Debe corresponder a la fila de encabezados. Se toleran mayúsculas/minúsculas y separadores _ - espacio (p. ej. TIPO-DOCUMENTO ≡ Tipo Documento). Si no coincide, el valor llega vacío (REQUIRED_FIELD_EMPTY).
  • Nombre de hoja (p. ej. Sheet1 vs Hoja1): debe existir en el archivo.
  • Al generar use .xlsx. El formato antiguo .xls no se lee.

Fechas y date_format

Si el tipo es date / datetime, indique el formato esperado (DD/MM/YYYY, MM/DD/YYYY, YYYY-MM-DD, etc.). Al generar y en vista previa el motor respeta la configuración del proyecto, no el formato regional del equipo.

  • Celdas fecha nativas de Excel se convierten a ese formato al leer.
  • Fechas como texto deben coincidir con el mismo patrón.
  • La salida del banco puede usar otro formato (salida / reglas de mapeo).

Propiedades de cada campo

PropiedadPara qué sirve
Nombre internoClave en el mapeo (M3). Minúsculas, sin espacios.
Columna / índiceDónde leer (letra, encabezado o índice según tipo).
Tipo contenidoForma esperada; si no cumple, la fila puede rechazarse (M5).
ObligatorioVacío → error de campo requerido.
Formato fechaObligatorio/recomendado si el tipo es fecha.
Patrón regexSi el tipo es custom; validación fullmatch.

Guía de tipos de contenido

SituaciónTipo sugerido
Nombres con espaciosalphanumeric_spaces o free_text
Teléfonos / guionesfree_text o custom con patrón
Montos 1.25 / 1,25custom + regex, p. ej. ^[0-9]+([.,][0-9]+)?$
Fechasdate + date_format
Enteros (edad, cantidad)numeric; en reglas de mapeo puede usar Numérico entero

Cómo se guarda

  • Parámetros de hoja: botón Guardar parámetros o Anterior / Siguiente.
  • Campos: se guardan al agregar / editar / eliminar cada uno.
  • Tras cambiar el borrador, publique de nuevo (M4) para que Generar use la versión actualizada.

Diagnóstico rápido (vista previa vacía o errores)

  • Revise Columna y nombre de hoja — no el nombre interno.
  • Confirme que el archivo es .xlsx y que la definición está publicada.
  • En fechas, revise date_format del campo frente al contenido real de la celda.
