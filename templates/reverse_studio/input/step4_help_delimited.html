Ayuda — Campos de la planilla (CSV / delimitado)

Para csv y txt_delimited: delimitador, comillas y columnas. El parser usa el índice 0-based.

← Volver al paso 4 Ir al paso 5

Qué es

El tipo del paso 1 es CSV o texto delimitado. Primero se parten las líneas con delimitador y comillas; después cada campo apunta a una columna. No hay hoja Excel ni letra A/B/C.

Flujo recomendado

  1. Elija el delimitador real del archivo (coma en CSV típico; punto y coma o tab en TXT).
  2. Marque si la primera fila es encabezado y, si aplica, el número de fila de títulos.
  3. Pulse Guardar parámetros antes de cargar muchos campos.
  4. Agregue campos: índice 0, 1, 2… y nombre interno. El texto «Columna del archivo» es referencia si hay encabezado.

Parámetros delimitador

ControlSignificado
Delimitador Coma, punto y coma, tabulador o pipe. Si no coincide con el archivo, todas las columnas se desalinean.
Carácter de comillas Envuelve valores que contienen el delimitador (normalmente "). Ejemplo: "Calle Sol, 12".
Carácter de escape Opcional. Escapa comillas internas. Vacío si el archivo no lo usa.
Primera fila es encabezado Esa fila no es un registro. Permite etiquetar columnas por nombre.
Fila encabezado Número 1-based de los títulos (suele ser 1). Visible con encabezado activo.

Editor de cada campo

ControlSignificado
Columna del archivo Nombre del encabezado (p. ej. DOC_ID). Referencia humana; el parseo usa el índice.
Nombre interno Clave para mapeo. No tiene que ser igual al encabezado.
Índice (0-based) Obligatorio. Primera columna = 0, segunda = 1. En nombre,edad,direccion, edad es 1.
Tipo / obligatorio / fecha / regex Validan el valor al generar. Ver guía más abajo.

Ejemplo

nombre,edad,direccion
Beatriz Martinez,19,Calle Parque 282
  • Delimitador: coma · Encabezado: sí · Fila encabezado: 1
  • nombre → índice 0 · edad → 1 · direccion → 2

Relación con captura (pasos 2–3)

El inicio/fin define qué filas se leen. Delimitador e índices definen cómo se parten. No confunda «fila encabezado = 1» con «inicio de captura = línea 2» si la línea 1 ya es un dato.

Si algo no encaja

SituaciónQué hacer
Todas las columnas mezcladasEl delimitador no coincide (coma vs punto y coma vs tab).
Valores con comas rotosRevise el carácter de comillas.
Campo siempre vacíoEl índice está mal (recuerde: 0-based, no letra Excel).
Encoding raro (ñ, acentos)Ajuste la codificación del paso 1, no este paso.

Qué no es

  • No es el editor Excel (hoja + letra de columna): eso aparece si el paso 1 es xlsx.
  • No define el layout de envío ni mapea campos.
  • La extensión al generar debe coincidir con el tipo publicado (.csv / delimitado).
