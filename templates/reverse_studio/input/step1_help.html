Ayuda — Tipo de planilla

Formato que enviará el negocio, encoding y fin de línea. Condiciona el paso 4 y las extensiones al generar.

← Volver al paso 1 Ir al paso 2

Qué es

Elige el tipo de planilla de entrada. No define el layout del banco/ERP (Salida) ni genera archivos. Solo se admiten tipos amigables: Excel, CSV y texto delimitado.

Flujo recomendado

  1. Elija el formato que el negocio ya sabe llenar (no el del banco, salvo que coincidan).
  2. Ajuste encoding y fin de línea en CSV / delimitado.
  3. Pulse Guardar borrador o Siguiente.
  4. Si ya había campos y cambia el tipo, confirme: puede limpiar el paso 4.

Campos de esta pantalla

ControlSignificado
Excel (xlsx) Hoja, encabezados y columnas se configuran en el paso 4. Al generar use .xlsx (no .xls antiguo).
CSV (csv) Delimitador y encabezados en el paso 4. La extensión al generar debe coincidir con el contrato publicado.
Texto delimitado (txt_delimited) Igual que CSV con otro delimitador (punto y coma, tab, etc.).
Codificación Cómo se leen los caracteres en CSV/delimitado. En Excel suele ser secundario.
Final de línea CRLF / LF / personalizado. Relevante en texto; en Excel casi no condiciona la lectura.
Guardar borrador / Siguiente Persiste en el borrador. ← Anterior vuelve al hub de entrada.

Si cambia el tipo

SituaciónResultado
Aún no hay camposPuede cambiar de tipo sin impacto.

Tipo fuera de lista (API)El servidor rechaza el guardado. La UI solo ofrece la whitelist.

Qué no es

  • No es el tipo de salida (posicional, XML, JSON van en Módulo 2).

  • Posicional, JSON y XML no son entrada Reverse en este producto.
