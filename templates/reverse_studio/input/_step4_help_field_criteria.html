Nombre interno y tipo de contenido

El nombre interno es la clave del contrato para mapeo (M3), reglas y generación. No tiene que coincidir con el encabezado del archivo. Minúsculas, sin espacios.

SituaciónTipo sugerido
Nombres con espaciosalphanumeric_spaces o free_text
Teléfonos / guionesfree_text o custom con patrón
Montos 1.25 / 1,25custom + regex, p. ej. ^[0-9]+([.,][0-9]+)?$
Fechasdate / datetime + date_format (DD/MM/YYYY, YYYY-MM-DD…)
Enteros (cantidad)numeric
Patrón propiocustom + regex fullmatch de todo el valor

Obligatorio vacío → error de campo requerido al generar. Fechas: el motor usa el formato del campo, no el regional del equipo. La salida del banco puede usar otro formato (Módulo 2 / reglas).
