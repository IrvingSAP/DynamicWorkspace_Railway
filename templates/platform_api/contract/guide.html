Ejes (no mezclar)

Qué: kind + project_slug, o kind=file_pipeline + pipeline_id.

Espera: wait=sync (HTTP 200 al terminar) o wait=async (HTTP 202 + consulta).

Atajo documentado: mode=pipeline equivale a kind=file_pipeline. El default de pipeline es async.
