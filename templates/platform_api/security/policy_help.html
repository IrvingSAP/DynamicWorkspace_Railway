Ayuda — Política de proceso

Límites HTTP de esta compañía. Complementan las keys: la key dice quién entra; esto dice qué se acepta al procesar.

Clientes ← Volver a la política

Para qué sirve esta pantalla

La capa API aplica estas reglas antes y alrededor del runner de Gate, Pipe o Pipeline. Un runner correcto no puede saltarse tamaño, tipo, rate, publicación, TTL de artifacts ni hosts de callback.

Solo US guarda. UA/UF no ven este formulario. La política es una por compañía (no por cliente).

Campos que puede ajustar

CampoEfecto en la APIAlta por defecto
Tamaño máximo (MB) Si el archivo lo supera: 400 — «El archivo supera el tamaño máximo permitido para esta compañía.» {{ default_max_mb }} MB
Solicitudes por minuto Por key. Al exceder: 429 — «Demasiadas solicitudes. Espere un minuto e intente de nuevo.» (p. ej. en whoami y run). {{ default_rate }} / min
TTL de artifacts (horas) Caducidad de enlaces firmados de informe/salida. Vencido: 404 opaco — «El enlace del artifact no es válido o ya expiró.» {{ default_ttl }} h
Extensiones Mismos tipos que el intake de las apps. Tipo ajeno: «Tipo de archivo no permitido. Use los mismos tipos que en la carga de la app.» {{ default_extensions }}
Hosts de callback Lista blanca anti-SSRF: un host por línea, sin https://. Solo HTTPS; se rechazan localhost, IPs privadas y userinfo. URL fuera de lista: «La URL de callback no está permitida.» Vacío = ningún callback de run/webhook pasa la URL

El secreto HMAC y los eventos se configuran en el detalle del cliente (webhooks), no aquí. Aquí solo se decide a qué hosts puede pegar la compañía.

Qué no se relaja desde este formulario

ReglaComportamiento
Solo versión publicada Run de proyecto o pipeline no publicado: 409 — «Solo se puede ejecutar una versión publicada.»
Dry-run y tablero Un dry-run no suma al pulso de Pipeline. No hay checkbox para activarlo.
IDs ajenos Job o artifact de otro tenant: 404 — «No se encontró el recurso.» (no se admite que existe).
Logs Metadatos y hashes. No cuerpos, celdas, Bearer ni key en claro.

Cómo probarlo

  • Suba un archivo más grande que el MB guardado → debe fallar validación de archivo.
  • Dispare GET /api/v1/whoami en bucle por encima del rate → 429.
  • Callback http://127.0.0.1/… o host que no esté en la lista → rechazo de URL.
  • Abra un enlace de artifact después del TTL → 404.

Qué no es esta pantalla

  • No crea ni rota keys — Clientes.
  • No define kinds ni wait — Contrato.
  • No lista runners — Integración.
