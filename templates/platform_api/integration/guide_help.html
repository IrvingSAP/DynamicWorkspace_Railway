Para qué sirve esta página

PLATFORM API ({{ catalog.identity.product_code }}) no es una app de archivos: no tiene project_kind ni ítem en el menú UF. Invoca el mismo runner que la UI de cada producto. El inventario vive en código; la máquina lo lee en GET {{ catalog.paths.integration|default:"/api/v1/integration" }}.

Un solo disparo HTTP: POST {{ catalog.single_run_path }}. El atajo POST {{ catalog.pipeline_alias }} es el mismo run con kind=file_pipeline.
