Referencia · FILE MATCH · Módulo 3 · {{ project.slug }}

Ayuda — Reglas de cruce

Cómo se emparejan filas A↔B, qué valores se contrastan y cómo se normaliza la clave.

← Volver al hub

Qué es este módulo

Declara las reglas de cruce del Conciliador. Se editan en borrador; se congelan al Publicar (Módulo 4) junto con Perfil A y Perfil B.

Secciones

#SecciónPara qué
1 Claves Pares A↔B que forman la clave 1:1 (compuesta si hay varios; el orden importa).
2 Comparar Valores a contrastar si la clave coincide. Cero pares = solo presencia.
3 Normalización trim / case_fold_keys y política de claves duplicadas.

Elementos comunes de la UI

  • Franja de alcance (arriba): compañía, código de proyecto y rol — contexto compartido en todas las pantallas de reglas.
  • Stepper de secciones: atajos Claves → Comparar → Normalize dentro del Módulo 3.
  • Los desplegables usan los name definidos en Perfil A y Perfil B.

Atajos útiles

  • Proponer pares 1:1 (hub): si A y B tienen los mismos nombres y aún no hay clave.
  • Tras proponer, revise siempre cuál campo es la clave de negocio.

Reglas de producto

  • Cardinalidad fija 1:1.
  • Al menos un par de clave para publicar.
  • No publica ni ejecuta desde aquí; siguiente paso típico: Publicar.
