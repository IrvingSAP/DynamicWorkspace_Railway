FILE MATCH · Módulo 4 · {{ project.slug }}

Ayuda — Publicar definición

Congela Perfil A + Perfil B + reglas de cruce en una versión activa. Conciliar es el módulo 5.

← Volver a publicar

Para qué sirve

Hasta publicar, A, B y reglas viven en el borrador. El job de conciliación no usa el borrador: solo la versión activa que sale de este paso.

No hay publicación parcial: o salen los tres bloques juntos, o no se publica. Completar los wizards A/B no basta; hay que pulsar Publicar vN aquí.

Qué ve en esta pantalla

ElementoSignificado
Borrador vN / Versión activa Número del borrador editable vs etiqueta de lo que ya está congelado (o «sin publicar»).
Pendiente Si aparece, lista ítems del checklist aún no listos. El botón Publicar queda deshabilitado.
Checklist Tres tarjetas con enlace: Perfil A, Perfil B y Reglas. Listo / Pendiente.
Publicar vN Solo PA / ED. Confirma y congela el snapshot. Pide confirmación en pantalla.
Continuar a ejecutar Va al módulo 5. Habilitado solo si ya hay versión activa.

Cuándo el checklist marca Listo

ÍtemCriterio
Perfil A 6/6 pasos, tipo permitido y al menos un campo.
Perfil B Igual para el lado B.
Reglas de cruce Hay clave usable y las reglas pasan validación estricta (sin errores de nombres A/B).

Qué se congela

  • Cómo leer A y B (tipo, captura, campos, reglas de contenido, informe de lectura).
  • Clave 1:1, campos a comparar y normalización de cruce.
  • No se congela el bridge FILE GATE como “definición de match”; el bridge se configura aparte y aplica al ejecutar.

Después de publicar

  • La versión que acaba de publicar pasa a activa.
  • Se abre un nuevo borrador (copia editable). Puede seguir diseñando sin romper las corridas en curso.
  • Los jobs nuevos usan solo la activa. Para que un cambio de campos o clave entre en vigor, vuelva a publicar.

Roles

  • PA / ED publican.
  • GE / CG / CO ven el estado; no confirman el publish.

Qué no hace este módulo

  • No sube archivos A/B ni ejecuta el cruce.
  • No publica “solo A” o “solo reglas”.
  • No sustituye FILE GATE: validar un archivo suelto es otra app (el bridge es opcional al conciliar).
