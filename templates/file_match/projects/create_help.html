Para qué sirve

Crea un proyecto con kind file_match: un espacio para definir cómo se leen los archivos A y B, las reglas de cruce 1:1 y, más adelante, conciliar. No es FILE GATE (un solo archivo), FilePipe (transformar) ni Reverse Studio (emitir).

Quien crea queda como administrador (PA). El alta no publica ni habilita conciliar: primero hay que completar Perfil A, Perfil B, Reglas y Publicar.

Campos de esta pantalla

CampoQué hace
Nombre corto (código) Slug único en la organización (compartido con Worksheets, FilePipe y el resto de apps). Use minúsculas y guiones; no se puede reutilizar un código ya tomado.
Nombre visible Título que verá el equipo en el listado y el hub (p. ej. «Conciliación banco vs ERP»).
Descripción Opcional. Contexto del cruce (periodos, proveedores, qué es A y qué es B).
Privado Solo miembros explícitos ven y trabajan el proyecto (según rol).
Público Los UF de la compañía pueden ver el proyecto. Editar, publicar o conciliar siguen exigiendo membresía y rol.

Acciones

  • Crear y continuar — alta el proyecto y abre el hub.
  • Cancelar — vuelve al listado sin guardar.

Qué hacer después

  1. (PA) Invite miembros si otras personas deben diseñar o ejecutar.
  2. Complete Perfil A (6 pasos) → Perfil B → Reglas.
  3. Publique A + B + reglas juntos.
  4. Concilie subiendo un archivo A y un archivo B.

Qué no hace este formulario

  • No define campos, claves ni publica la definición.
  • No sube archivos de conciliación.
  • No crea un contrato FILE GATE ni un mapeo FilePipe.
