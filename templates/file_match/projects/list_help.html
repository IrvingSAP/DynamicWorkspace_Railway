Ayuda — Listado de proyectos

Proyectos de conciliación A vs B de su compañía: qué ve, qué significan las columnas y cómo empezar.

← Volver al listado

Qué es este listado

Es la puerta de entrada a FILE MATCH (Conciliador). Cada fila es un proyecto con kind file_match: compara dos orígenes (A vs B) por clave 1:1 y produce un informe de diferencias. Está aislado de FilePipe, FILE GATE y Reverse Studio.

  • Solo se listan proyectos de su compañía (alcance UF).
  • Aparecen los proyectos donde usted es miembro y los públicos de la compañía (aunque no sea miembro).
  • Desde aquí crea un proyecto nuevo o abre el hub de uno existente.

Tarjetas de resumen

IndicadorSignificado
TotalProyectos FILE MATCH visibles para usted en esta compañía.
ActivosNo archivados (disponibles para trabajo).
Como admin (PA)Proyectos donde su rol es administrador.
Públicos compañíaVisibilidad pública: cualquier UF de la compañía puede verlos.

Columnas de la tabla

ColumnaQué muestra
CódigoSlug único del proyecto en la compañía; enlace al hub.
NombreNombre visible del conciliador.
VisibilidadPrivado (solo miembros) o Público (la compañía puede verlo).
Mi permisoSu rol en el proyecto (PA / ED / GE / CO) o consulta si solo lo ve por ser público.
VersiónEstado de la definición (borrador / versión publicada activa, según el proyecto).
AccionesAbrir el hub del proyecto.

El filtro de Visibilidad en la barra de la tabla permite restringir a públicos o privados.

Visibilidad y acceso

  • Privado: solo membresía activa puede ver y trabajar según el rol.
  • Público: UF de la misma compañía pueden ver el proyecto sin ser miembros (consulta). Editar, publicar o conciliar siguen exigiendo el rol adecuado.
  • El creador queda siempre como PA, independientemente de la visibilidad.

Roles (resumen)

RolPermisos principales
PAAdmin: miembros, editar definición, publicar, conciliar, bridge.
EDEditar Perfil A/B y reglas; publicar; conciliar.
GEConciliar y descargar informe (sin editar definición).
COConsulta: ver hub e historial; sin filas de negocio ni descargas de datos.

Los miembros se gestionan dentro de cada proyecto (hub → Miembros, solo PA).

Cómo empezar

  1. Pulse + Nuevo proyecto (nombre, código/slug y visibilidad).
  2. En el hub, complete Perfil A → Perfil B → Reglas.
  3. Publique la definición.
  4. Concilie subiendo archivos A y B; revise informe e historial.

Regla de producto: no se concilia sin versión publicada. Guía completa: menú FILE MATCH → Ayuda.

Qué no es este listado

  • No muestra proyectos de FilePipe, FILE GATE ni Reverse Studio.
  • No edita perfiles ni reglas (eso ocurre en el hub de cada proyecto).
  • No ejecuta conciliaciones ni sube archivos A/B.
