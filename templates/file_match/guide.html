Cómo funciona FILE MATCH

FILE MATCH (Conciliador) cruza un archivo A con un archivo B por clave (1:1) y entrega un informe de diferencias — sin generar un tercer archivo de negocio.

Esta página describe el flujo completo. En cada pantalla también hay ayuda contextual (botón ? / Ayuda) con el detalle de esa vista.

Ruta rápida

  1. Cree un proyecto y defina Perfil A y Perfil B.
  2. Configure reglas de cruce, publique la versión.
  3. Suba A + B, concilie y revise informe / historial.
Roles PAAdmin — define, publica, miembros, bridge EDEditor — ajusta perfiles/reglas y concilia GEEjecutar — concilia y descarga informe COConsulta — historial/metadatos; sin filas

Qué es FILE MATCH

Es el aplicativo de DynamicWorkspace para equipos de tesorería, control, operaciones e integradores que necesitan cuadrar dos extractos o listados (banco vs ERP, nómina vs pagos) con evidencia auditable.

En una frase

Un conciliador de archivos: dos orígenes, cero destino de negocio, informe de matched / only_a / only_b / mismatch.

Resultado que entrega

  • Veredicto: cuadra / no cuadra / parcial.
  • Informe y descarga JSON/CSV de diferencias (roles con permiso).
  • Certificado ligero e historial filtrable.
2

Cuál es la función de esta app

Función principal: leer A y B con los parsers DMS → cruzar por clave 1:1 → comparar campos seleccionados → emitir informe contra la definición publicada.

Problema que resuelve

  • Cuadres en Excel / VLOOKUP frágiles y poco auditables.
  • Falta de versión de reglas y de quién concilió qué.
  • Necesidad de evidencia (hashes, veredicto, TTL de descargas).

Qué ganas

  • Misma definición reutilizable cada ciclo.
  • Roles claros (diseñar vs ejecutar vs consultar).
  • Opcional: exigir FILE GATE en A y/o B antes de conciliar.
3

Qué no es (y qué sí usar en su lugar)

FILE MATCH no…

  • No genera un tercer archivo “ya conciliado”.
  • No es un validador de un solo archivo (solo gate).
  • No emite layout de banco ni hace fuzzy match / IA en el MVP.

Usa otra app si…

  • FILE GATE — validar que un archivo cumple un contrato.
  • Reverse Studio — emitir layout rígido desde planilla.
  • FilePipe — ETL genérico origen → destino.

Flujo de trabajo

Camino fijo del producto: definir A y B → publicar → conciliar → auditar.

  1. Crear proyecto Conciliador y (si aplica) asignar miembros.
  2. Completar Perfil A y Perfil B (tipo, captura, campos, reglas de contenido).
  3. Definir claves de cruce y campos a comparar; publicar.
  4. (Opcional) Activar integración FILE GATE para A y/o B.
  5. Subir A + B, ejecutar, revisar informe e historial.
