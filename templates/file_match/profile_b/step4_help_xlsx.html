Para qué sirve esta pantalla

El archivo B es un libro Excel. FILE MATCH lee una hoja y toma celdas por columna (letra o encabezado). No genera una hoja de salida: solo parsea B para el cruce.

Acciones de esta pantalla

ControlQué hace
Guardar parámetrosPersiste hoja y fila de encabezados en el borrador B.
+ Agregar campoNuevo criterio ligado a una columna.
← ResumenVuelve al hub del Perfil B.

Parámetros de hoja

Campo en pantallaEfecto
Nombre de hojaNombre exacto de la pestaña. Si no coincide, no hay filas B.
Fila de encabezadosFila (1-based) con títulos. Permite referenciar columnas por texto además de por letra.

Editor de cada campo

Campo en pantallaEfecto
ColumnaLetra Excel (A, AA) o texto del encabezado.
Nombre internoIdentificador en informe B y reglas de cruce.
Tipo / obligatorio / fechaCriterios de rechazo de la celda.

Ejemplo

  • Hoja Extracto, encabezados en fila 1: DOC, MONTO.
  • Campo documento → columna A o encabezado DOC.
  • Campo monto → columna B, tipo decimal.

Otras pestañas del libro se ignoran. La captura (pasos 2–3) limita qué filas de la hoja entran.
