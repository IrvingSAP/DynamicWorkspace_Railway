Ayuda — Copiar desde Perfil A

Atajo cuando A y B tienen el mismo layout: clona el borrador A al borrador B sin repetir el wizard.

{% if request.GET.from == "confirm" %} ← Volver a confirmar {% else %} ← Perfil B {% endif %}

Qué hace

Copia tipo, encoding, captura, campos, reglas de contenido e informe de lectura del borrador Perfil A al borrador Perfil B del mismo proyecto. Es un clone snapshot (no vínculo vivo).

Cuándo usarlo

  • Ambos archivos tienen la misma estructura (mismos campos / mismo tipo).
  • Quiere evitar repetir los 6 pasos del asistente B.
  • El Perfil A ya tiene tipo y al menos un campo.

Reglas 1:1 (opcional)

  • En la confirmación puede marcar Proponer pares 1:1 en Reglas.
  • Si las reglas aún no tienen clave: el primer campo homónimo pasa a clave; el resto a comparar.
  • Revise siempre el Módulo 3: la clave de negocio puede no ser el primer campo.

Qué no hace

  • No publica la definición Match (Módulo 4).
  • No sustituye Importar estructura desde FILE GATE (PROFILE SEED en Perfil A).
  • No es el bridge FILE GATE (hash de job).
  • Si B ya tiene campos, se sobrescriben tras confirmar.

Roles

Solo PA / ED (permiso de editar definición).
