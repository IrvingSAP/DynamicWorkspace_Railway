Ayuda — Reglas globales de contenido

Normalización y exclusiones a nivel de línea o archivo A, aplicadas al leer. Complementan los campos del paso 4; no son las reglas de cruce A vs B.

← Volver al paso 5

Para qué sirve

El paso 4 declara qué debe cumplir cada campo A. Este paso declara qué líneas ni siquiera deberían parsearse como dato (vacías, comentarios) y qué caracteres o patrones invalidan la línea entera.

Se guarda como content_rules en el borrador A. Las violaciones salen en el informe de lectura del lado A (paso 6) al conciliar. El veredicto del match (cuadra / no cuadra) lo deciden las Reglas de cruce (Módulo 3), no este paso.

Normalización de líneas

OpciónEfecto al leer A
Quitar espacios
trim_lines		 Recorta espacios al inicio y al final antes de validar campos.
Ignorar líneas en blanco
skip_empty_lines		 Las líneas vacías (tras el trim, si está activo) no se parsean ni entran al cruce.
Prefijo de comentarios
comment_prefix		 Líneas que empiezan por ese texto se omiten. Vacío = no hay comentarios.

Caracteres y patrones

OpciónEfecto
Caracteres permitidos
allowed_chars		 Lista blanca opcional. Vacío = no restringe.
Caracteres excluidos
excluded_chars		 Lista negra (uno por línea; p. ej. \x00). Rechazo FORBIDDEN_CHAR.
Patrones prohibidos
forbidden_patterns		 Regex, una por línea. Si coincide, se rechaza la línea entera.

Orden al conciliar el archivo A

  1. Captura (pasos 2 y 3): solo esa franja se lee.
  2. Estas reglas globales (trim, vacías, comentarios, caracteres, patrones).
  3. Campos del paso 4.
  4. Informe de lectura A (paso 6). Luego el motor cruza con B según Reglas.

Qué no hace este paso

  • No define tipos ni obligatoriedad por campo: eso es el paso 4.
  • No define clave 1:1 ni campos a comparar: eso es el módulo Reglas.
  • No decide el veredicto del conciliador ni publica la definición.

Buenas prácticas

  • Active trim y saltar vacías si el proveedor rellena o deja huecos.
  • No ponga en lista negra un delimitador que el paso 4 necesita.
  • Use patrones prohibidos para marcas de error del archivo, no para validar un campo concreto.
  • Solo PA y ED pueden guardar. El stepper marca este paso ✓ cuando hay reglas persistidas.
