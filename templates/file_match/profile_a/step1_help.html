Qué decide este paso

Sin tipo de archivo no se puede publicar el contrato. La elección condiciona la pantalla de campos (paso 4): posiciones fijas, columnas delimitadas, hoja Excel, JSON o XML.

ElementoEfecto en la validación
Tipo de archivo Formato esperado (txt_fixed, csv, txt_delimited, xlsx, …). Las extensiones permitidas al conciliar salen de este tipo.
Encoding Cómo se leen los bytes del archivo. Un encoding incorrecto suele producir caracteres inválidos o rechazos de contenido.
Fin de línea Cómo se parten las líneas (LF, CRLF o auto). Debe coincidir con el archivo real del proveedor.

Buenas prácticas

  • Elija el tipo que usa el proveedor; no “el más flexible”.
  • Si ya hay campos definidos y cambia el tipo, revise el paso 4: la estructura anterior puede quedar inválida.
  • Solo PA y ED pueden guardar. El resto ve el paso en solo lectura.
