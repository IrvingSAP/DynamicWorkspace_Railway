Ayuda — Campos de ancho fijo

Cada campo se corta por posiciones de carácter en la línea del archivo A. Tipo: {{ file_type_code|default:"txt_fixed" }}.

← Volver al paso 4

Para qué sirve esta pantalla

El archivo A es una línea continua (TXT posicional). FILE MATCH extrae cada valor por columnas de carácter (1 = primer carácter) y lo valida contra tipo, obligatoriedad y patrón. La regla visual alinea rangos; no es el archivo del proveedor.

Acciones de esta pantalla

ControlQué hace
+ Agregar campoAbre el editor para un nuevo criterio posicional.
Editar / quitar en la tablaModifica o elimina un campo del borrador A.
← ResumenVuelve al hub del Perfil A sin publicar.
Anterior / SiguientePaso 3 (fin) o paso 5 (reglas globales).

Editor de cada campo

Campo en pantallaEfecto al leer A
Nombre (slug)Identificador interno. Informe de lectura y reglas de cruce.
EtiquetaTexto legible. No sustituye al nombre interno.
Cómo definir la posición
  • Inicio y fin — primera y última columna inclusive (1-based).
  • Inicio y longitud — end = start + length − 1.
  • Desde carácter — el valor empieza a partir de un marcador.
Inicio / fin / longitudColumnas 1-based. Los rangos numéricos no deben solaparse.
Marcador charEn modo «desde carácter»: el campo inicia al encontrar ese texto.
Tipo / obligatorio / patrónCriterios de rechazo del recorte.

Ejemplo

12345JUAN      2500001
  • documento → inicio 1, fin 5.
  • nombre → inicio 6, longitud 10 (columnas 6–15).
