Criterios de rechazo

En FILE MATCH cada campo es un criterio de conformidad, no un origen para mapear a un destino. Al publicar se exige al menos un campo.

PropiedadSignificado en el gate
NombreIdentificador del campo en el informe y en las incidencias.
Tipo de contenidoQué forma se espera (texto, número, fecha, enum…). Un valor incompatible genera error de contenido.
ObligatorioSi está vacío, cuenta como rechazo (según políticas de umbral).
Patrón / reglasExpresiones o restricciones adicionales; si no cumplen, la fila/campo se reporta.

Según tipo de archivo

TipoQué define
txt_fixedPosiciones: inicio/fin, inicio/longitud o marcador de carácter. Use la regla de vista previa para alinear columnas.
csv / txt_delimitedDelimitador, comillas, fila de encabezado y columna (nombre o índice) por campo.
xlsxHoja, fila de inicio y columna (letra o encabezado) por campo.
jsonRuta al arreglo de registros y json_path de cada campo.
xmlElemento repetido y etiqueta hijo por campo.
