FILE MATCH · Perfil A · paso 6 · {{ project.slug }}

Ayuda — Informe de lectura (lado A)

Define qué evidencia se registra al parsear el archivo A en una conciliación. No es el informe de diferencias A vs B.

← Volver al paso 6

Para qué sirve

Aquí congela qué se documenta al leer A: resumen de filas parseadas, detalle por fila y formato. El job de conciliación (Módulo 5) produce esa evidencia contra la definición publicada.

Completar este paso no publica Match ni habilita conciliar. Faltan Perfil B, Reglas y publicar (Módulo 4).

Opciones del informe

OpciónEfecto al conciliar
Informe habilitado
report_enabled		 Si está apagado, A puede parsearse pero con poca o ninguna evidencia de lectura.
Incluir resumen
include_summary		 Filas leídas, OK y rechazadas al parsear A.
Detalle por fila
include_row_errors		 Incidencias: línea, campo, código y mensaje del parseo A.
Umbral de alerta Aviso si hay demasiados rechazos de lectura (cantidad o %). No es el veredicto del match.
Formato
report_format		 json, csv o html.

Este paso vs el resto de FILE MATCH

DóndeQué decide
Paso 6 Perfil A (aquí) Evidencia de lectura del archivo A.
Reglas (Módulo 3) Clave 1:1, campos a comparar y normalización de cruce.
Informe de conciliación (Módulo 6) Qué faltó, qué sobró y qué no coincidió entre A y B.
Publicar (Módulo 4) Congela A + B + reglas. Sin versión publicada no se concilia.

Guardar este paso

  • Guardar borrador persiste el informe de lectura. Si faltan pasos del Perfil A (p. ej. Campos), verá un aviso: el borrador se guardó, pero el ciclo de 6 pasos no está completo.
  • Finalizar perfil A vuelve al hub A. El stepper marca Informe ✓ cuando hay processing_report guardado.
  • Solo PA y ED pueden guardar.

Qué no hace este paso

  • No publica la definición Match.
  • No ejecuta la conciliación ni sube archivos A/B.
  • No configura el Perfil B ni las reglas de cruce.

Buenas prácticas

  • Deje el informe habilitado con resumen y detalle: sin evidencia de parseo A es difícil auditar un “no cuadra”.
  • Siguiente en el ciclo: hub Perfil A → Perfil B.
