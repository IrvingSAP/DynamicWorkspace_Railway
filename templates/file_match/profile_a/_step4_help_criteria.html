Criterios de rechazo (todos los tipos)

En FILE MATCH cada campo es un criterio de lectura del archivo A, no un origen para mapear a un destino. Al publicar la definición (A + B + reglas) se exige al menos un campo en A. Las incidencias de parseo usan el nombre interno.

PropiedadSignificado al conciliar
Nombre interno Identificador único. Sale en el informe de lectura A y en las reglas de cruce (clave / comparar).
Tipo de contenido Forma esperada. Un valor incompatible genera error de contenido al parsear A.
Campo obligatorio Vacío → rechazo de lectura. No es el veredicto del match 1:1.
Patrón / formato fecha Si el tipo es custom, regex. Si es fecha, indique el formato (p. ej. DD/MM/YYYY).

Acciones de esta pantalla: + Agregar campo, editar/quitar filas, Guardar parámetros (si aplica al tipo) y Siguiente al paso 5. El stepper marca Campos ✓ solo si hay al menos un campo guardado. Opcional: Importar estructura desde el hub A. Solo PA y ED editan.
