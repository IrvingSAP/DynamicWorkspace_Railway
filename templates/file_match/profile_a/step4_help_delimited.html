Ayuda — Campos delimitados (CSV / TXT)

Parte cada línea por un delimitador y lee columnas del archivo A. Tipo: {{ file_type_code|default:"csv" }}.

← Volver al paso 4

Para qué sirve esta pantalla

El archivo A es una tabla en texto. Primero se configuran delimitador, comillas y encabezado; después cada campo apunta a una columna. El parser usa el índice 0-based; el nombre de columna es referencia cuando hay encabezado.

Acciones de esta pantalla

ControlQué hace
Guardar parámetrosPersiste delimitador, comillas, escape y encabezado en el borrador A.
+ Agregar campoNuevo criterio ligado a una columna.
← ResumenVuelve al hub del Perfil A.

Guarde los parámetros antes de cargar muchos campos.

Parámetros del archivo

Campo en pantallaEfecto al leer A
DelimitadorComa, punto y coma, tabulador o pipe. Si no coincide, todas las columnas se desalinean.
Carácter de comillasEnvuelve valores que contienen el delimitador (p. ej. "Calle Sol, 12").
Carácter de escapeOpcional. Vacío si el archivo no lo usa.
Primera fila es encabezadoEsa fila no es un registro A. Permite etiquetar columnas por nombre.
Fila encabezadoNúmero de fila (1-based) de los títulos. Visible con encabezado activo.

Editor de cada campo

Campo en pantallaEfecto
Columna del archivoNombre del encabezado (referencia). El parseo usa el índice.
Nombre internoIdentificador en informe A y en reglas de cruce.
Índice (0-based)Primera columna = 0. Obligatorio.
Tipo / obligatorio / fechaCriterios de rechazo de esa columna.

Ejemplo

nombre,edad,direccion
Beatriz Martinez,19,Calle Parque 282
  • Delimitador: coma · Encabezado: sí · Fila 1
  • nombre → índice 0 · edad → 1 · direccion → 2
