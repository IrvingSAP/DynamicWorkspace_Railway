Para qué sirve esta pantalla

El archivo A es un documento XML. FILE MATCH recorre cada ocurrencia de un elemento repetido y lee el texto de etiquetas hijo. Cada etiqueta es un criterio de lectura A, no un mapeo a otro XML.

Acciones de esta pantalla

ControlQué hace
Guardar parámetrosPersiste el elemento repetido en el borrador A.
+ Agregar campoNuevo criterio con su etiqueta hijo.
← ResumenVuelve al hub del Perfil A.

Parámetros XML

Campo en pantallaEfecto
Elemento repetido
record_element		 Nombre local del nodo que se repite (sin namespace). Ej.: empleado, item.

Editor de cada campo

Campo en pantallaEfecto
Nombre internoIdentificador en informe y reglas (puede diferir de la etiqueta XML).
element Etiqueta hijo dentro del registro. Ej.: documento.
Tipo / obligatorioCriterios de rechazo del texto del elemento.

Ejemplo

<nomina>
  <empleado>
    <documento>A1</documento>
    <edad>19</edad>
  </empleado>
</nomina>
  • record_element = empleado
  • Campo documento → element documento
  • Campo edad → edad, tipo numérico

El nombre local no lleva prefijo de namespace. Una etiqueta distinta deja el valor vacío.
