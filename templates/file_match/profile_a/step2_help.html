FILE MATCH · Perfil A · paso 2 · {{ project.slug }}

Ayuda — Inicio de captura

Define desde qué punto del archivo A empiezan las filas a leer. Todo lo anterior se omite y no entra al cruce.

← Volver al paso 2

Para qué sirve

El archivo A (extracto, libro, layout) casi nunca es “solo datos”: suele traer título, fecha o líneas de control antes del detalle. Si el inicio está mal, FILE MATCH trata esa basura como filas A: fallan campos y el match 1:1 compara claves que no existen en el negocio.

Este paso guarda capture_start en el borrador A. La unidad es siempre líneas (1 = primera línea del archivo).

Qué entra y qué se ignora

Zona del archivo AEfecto al conciliar
Antes del inicio Se omite. No genera errores de campo ni filas de cruce.
Desde el inicio hasta el fin (paso 3) Cada registro se parsea con el Perfil A y entra al match si supera la lectura.
Después del fin Lo define el paso 3. Aquí solo fija el arranque.

Modos de inicio

ModoCuándo usarloCómo arranca
Primera línea
first		 El archivo A es puro detalle. Línea 1 inclusive.
Línea específica
line_number		 Cabecera con el mismo número de líneas siempre. La línea indicada (1-based) inclusive.
Tras N líneas
after_header_block		 Quiere “saltar N líneas”, no “empezar en la línea N”. Con skip_lines = 3 la primera fila leída es la 4.
Marcador de inicio
marker_start		 Un texto fijo anuncia el detalle. La línea siguiente a la primera que contiene el texto.
Tras patrón regex
after_pattern		 El anuncio varía pero encaja en una expresión. La línea siguiente a la primera coincidencia.
Tras líneas en blanco
after_blank_run		 El detalle empieza después de un hueco vacío. Tras N líneas vacías consecutivas, la inmediata siguiente.

Coherencia con el paso 3

El fin debe quedar después de este inicio, en la misma unidad (líneas). Con fin en EOF se lee desde este arranque hasta la última línea del archivo A.

Buenas prácticas

  • Mida el archivo A real, no un ejemplo limpio de laboratorio.
  • Prefiera número de línea o marcador literal antes que regex, si basta.
  • El Perfil B tiene su propio inicio de captura; no se copia automáticamente desde A (salvo que use Copiar A→B).
  • Solo PA y ED pueden guardar.
