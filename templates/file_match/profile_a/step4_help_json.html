Para qué sirve esta pantalla

El archivo A es un documento JSON. FILE MATCH recorre un arreglo de registros y, en cada uno, lee propiedades por ruta con puntos. Cada ruta es un criterio de lectura A, no un mapeo a otro JSON.

Acciones de esta pantalla

ControlQué hace

+ Agregar campoNuevo criterio con su json_path.

Parámetros JSON

Campo en pantallaEfecto
Ruta de registros
record_path		 Camino hasta el array. Ej.: empleados, data.items. Cada elemento es una fila A.

Editor de cada campo

Campo en pantallaEfecto
Nombre internoIdentificador en informe y reglas (puede diferir de la clave JSON).
json_path Ruta relativa dentro de cada registro (puntos). Ej.: documento, persona.edad.
Tipo / obligatorioCriterios de rechazo del valor en esa ruta.

Ejemplo

{
  "empleados": [
    { "documento": "A1", "persona": { "edad": 19 } }
  ]
}
  • record_path = empleados
  • Campo documento → json_path documento
  • Campo edad → persona.edad, tipo numérico

Una ruta incorrecta deja el valor vacío y dispara obligatorio o tipo.
