Ayuda — Enrutado

Hacia qué runner apunta el lote si Watch dispara al llegar. Al elegir el modo, se despliega un panel distinto. Guardar no cambia el estado de la bandeja.

← Volver a Enrutado

Propósito de la página

El origen ya sabe de dónde viene el archivo y Intake cómo lo guarda. Enrutado dice qué Job o pipeline se encola cuando el disparo es «Al llegar».

  • Una sola definición por bandeja. Al pulsar Job, Pipeline o Diferir, el formulario muestra solo ese panel.
  • El plan de File Scheduler con input_origin=watch usa el destino del plan, no este enrutado. Esta pantalla aplica al camino «disparo al llegar».
  • Editar con la bandeja Activa: el próximo fire usa el nuevo destino; no cancela Jobs ya encolados.
  • Job y Pipeline exigen versión publicada (y pipeline Activo). Se usa la publicada vigente al encolar.

Quién puede usarla

RolQué puede hacer
PA / ED Ver y guardar el enrutado.
GE / CO Solo lectura. Sin «Guardar enrutado».

Modo (siempre visible)

Elige el adaptador de destino y despliega el panel correspondiente. Los otros paneles se ocultan.

ModoQué haceCuándo usarlo
Job de app Al disparar, encola el runner de un proyecto publicado (misma compañía). Ej. extracto → File Gate al llegar.
Pipeline Al disparar, arranca un pipeline activo con versión publicada. Cadena (p. ej. Gate → Pipe) al llegar.
Diferir Watch no elige runner; solo deja el lote Pendiente. El destino lo pone el plan Scheduler (u otro consumidor). Ingesta ahora, Job a la hora del cron. Por defecto en el formulario.

Si elige Job de app

Aparece el panel Job. Al cambiar la app se recarga el listado de proyectos de esa app.

CampoObligatorioFunciónValores
App Sí Qué vertical ejecutará el Job. No use File Pipeline aquí: eso es el modo Pipeline. File Gate · File Pipe · File Clean · File Match · Reverse Studio · Structure Scout · File Split · File Merge
Proyecto Sí Proyecto de esa app en esta compañía, con versión publicada. Sin publicada aparece deshabilitado. «— Elija —» y el nombre del proyecto. Debe coincidir con la app.

El historial del Job vive en esa app, no en File Watch.

Si elige Pipeline

Aparece el panel Pipeline. No pide app ni proyecto suelto: la cadena ya está en el pipeline.

CampoObligatorioFunciónValores
Pipeline Sí Pipeline de esta compañía, estado Activo y versión publicada. Si no cumple, la opción está deshabilitada. «— Elija —» y el nombre del pipeline

El historial de la corrida vive en el tablero File Pipeline.

Si elige Diferir

No hay campos extra. El lote queda Pendiente en Intake; File Scheduler (u otro) define el Job al hacer claim. Compatible con disparo «Solo pendiente». Incompatible con «Al llegar».

Situación¿Se puede guardar / activar?
Diferir + disparo Solo pendiente Sí. El destino lo pone el plan.
Diferir + disparo Al llegar (ya guardado) No. Mensaje: «Al llegar» no es compatible con enrutado Diferir. Elija Job/Pipeline o cambie el disparo.
Al llegar + Job o Pipeline publicado Sí. Hace falta este enrutado para marcar la bandeja Activa.
Proyecto o pipeline sin publicada No. El destino no tiene una versión publicada operativa.
