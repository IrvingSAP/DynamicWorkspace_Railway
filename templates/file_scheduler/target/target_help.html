Ayuda — Destino del plan

Qué se ejecutará, de dónde sale el archivo y cómo completar Artifact o Watch.

← Formulario

Propósito

Define qué Job o pipeline encolará el tick y de dónde sale el archivo. No define el reloj (Programación) ni las rutas IFS (eso es File Watch). Guardar no cambia el estado del plan. Solo PA y ED pueden guardar.

Qué origen elegir

El error «Indique la referencia del artifact» aparece cuando eligió Artifact y el campo quedó vacío. Si no tiene un hash de un Job anterior, no use Artifact: use File Watch.

OrigenÚselo si…Qué debe rellenar
File Watch El archivo llega (o ya está) en una bandeja vigilada. Caso típico de cierre nocturno o extracto diario. Código de la bandeja (slug, ej. extracto-sftp). No el hash del archivo.
Artifact Va a reprocesar un archivo que ya corrió en Gate, Pipe, Clean, etc. y del que conoce el hash. Hash SHA-256 fijo (ver abajo). No es el código de una bandeja.
Sin archivo Solo Pipeline cuya cadena no pide upload en el tick (entradas ya resueltas en los pasos). Casilla de confirmación. Sin bandeja ni hash. Prohibido si el modo es Job de app.

Hash del artifact — qué pegar

Es el identificador del contenido ya guardado en storage del tenant, no un «adjuntar archivo».

AceptadoNo ponga esto
Hash SHA-256 en hexadecimal (64 caracteres), como el hash de entrada de un Job en el historial de Gate/Pipe/Clean/Match. Nombre de archivo (extracto.csv), ruta Windows, URL http, carpeta IFS o código de Watch.
Opcional: prefijo sha256: + el mismo hex. Máximo 128 caracteres. Un archivo vacío o un texto de prueba. El tick no inventa un fichero.

Dónde copiarlo: abra el historial de la app destino → detalle del Job → hash de entrada / content_hash. Pegue ese valor en Hash del artifact.

Si aún no hay Jobs con hash, cambie el origen a File Watch y ponga el código de la bandeja. Artifact queda para reprocesos, no para el alta del plan.

Modo Job o Pipeline

ModoQué se encolaRequisito
Job de appUn proyecto de Gate, Pipe, Clean, Match, Reverse, Scout, Split o Merge.Versión publicada en esa app. Historial en esa app, no en el tablero de pipelines.
PipelineLa cadena ya diseñada.Pipeline Activo con versión publicada. El tick no rediseña pasos.

Errores frecuentes

MensajeQué hacer
Indique el hash SHA-256 del artifactEligió Artifact y el campo está vacío. Pegue el hash o cambie a File Watch.
Indique el código de la bandejaEligió File Watch sin slug. Ponga el código de la bandeja (no un hash).
Sin archivo + JobUn Job de archivo no puede ir sin entrada. Use Watch o Artifact, o cambie a Pipeline con confirmación.
Sin versión publicadaPublique el contrato/pipeline en su app antes de apuntarlo aquí.

Permisos y al guardar

Debe poder ejecutar el proyecto (o todos los pasos del pipeline). US de la compañía puede apuntar destinos de su compañía. UF PA/ED del plan necesita rol ejecutor en cada proyecto destino.

Guardar registra schedule.updated. Si el plan ya está Activo, el próximo tick usa la nueva definición; no cancela un Job ya encolado. Activar / Reanudar sigue exigiendo también Programación (M2) o Dependencia (M6).
