Ayuda — Errores del Scheduler

Cómo se informan los fallos y qué no es un código schedule_*.

← Catálogo

Propósito

El código es para el servicio y la auditoría. El usuario ve el mensaje de negocio.

  • Capa 1: otra compañía o plan inexistente → 404, sin código schedule.
  • Capa 2: guardar el plan (inline o modal).
  • Capa 3: el worker no encoló (Actividad / Auditoría).
  • Capa 4: Gate rechazó o falló un paso → abrir el Job o el pipeline; no hay schedule_gate_*.

Omitir vs fallar

schedule_overlap_skip es una omisión (política de solape), no un error de formulario. schedule_misfire es una ventana perdida; no se disparan todas las atrasadas de golpe.
