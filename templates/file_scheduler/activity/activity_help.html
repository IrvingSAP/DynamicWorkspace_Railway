Ayuda — Actividad / ticks

Qué registra el worker, por qué Mensaje puede ir vacío y dónde está el log del Job.

← Actividad

Propósito

Lista los ticks de este plan. Un tick es un intento de encolar en una ventana scheduled_for. No es el historial de File Gate, File Pipe ni File Clean, ni el tablero de pasos de pipeline. El worker solo evalúa planes Activos. Identidad: system:scheduler. No hay Ejecutar ahora.

Dónde está el log

Esta pantalla solo dice si el Scheduler encoló, omitió o no pudo encolar. El resultado de negocio (¿terminó? ¿error de filas? ¿informe?) vive en la app destino.

Destino del planDónde abrir el detalle
Job File Gate / Pipe / Clean / Match…Columna Run → historial o resultado de esa app. Requiere un usuario UF miembro del proyecto. Un usuario US puede ver el tick aquí, pero no abrir el historial de la app.
PipelineColumna Run → corrida en File Pipeline (rail de pasos).

En local, el worker de ticks es python manage.py process_schedule_ticks --loop. Con origen Artifact, el tick busca el hash en storage e invoca el runner de File Clean, File Gate o File Pipe (el mismo que la UI/API). El historial de esa app muestra la corrida. Match, Split/Merge, Reverse y Scout aún no se ejecutan desde el Scheduler.

Resultados

EstadoSignificadoMensaje
Encolado El runner de la app arrancó (o el pipeline). El negocio se lee en el historial de esa app. Vacío o texto de seguimiento. No es un error.
En curso El run delegado sigue vivo: queued, uploaded o running. Indica que sigue en cola o ejecutándose. Abra el historial de la app.
Omitido No encoló: misfire (ventana perdida > 15 min) o solape (run anterior vivo). Texto del catálogo (schedule_misfire, schedule_overlap_skip).
Falló Error del Scheduler antes de encolar (sin publicada, sin entrada, cola). Código schedule_*. Un Job que ya corrió y falló en Gate/Clean no cambia este estado.

Columnas

ColumnaQué muestra
VentanaInstante scheduled_for del slot (timezone del plan).
ResultadoEstado del tick (arriba). Independiente del estado del plan.
MensajeSolo errores/omisiones del Scheduler, o una pista si el Job destino sigue en cola. Sin filas del archivo.
RunEnlace al historial o resultado de la app destino.

Misfire

Si el worker llega más de 15 minutos tarde, no dispara esa ventana ni las anteriores de golpe. Registra omitido (schedule_misfire) y sigue con la próxima.

Un origen File Watch sin lote resuelto no inventa archivo: el tick falla con falta de entrada.
