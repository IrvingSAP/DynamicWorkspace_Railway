Servicios

Todo lo que tu equipo necesita para gestionar datos operativos

Tablas configurables, transformación de archivos y apps especializadas (validador, emisor, conciliador y explorador) sobre el mismo chasis multi-compañía.

Capacidades de plataforma

Lo que comparte toda la suite: proyectos, permisos, auditoría, importación y seguridad.

📋

Gestión de proyectos

Cada proyecto es una unidad de trabajo dentro de tu compañía. Crea, archiva y organiza sin tocar código.

  • Creación de proyectos con nombre, descripción y slug
  • Campos dinámicos en Worksheets: texto, número, fecha, lista, booleano
  • Archivado sin pérdida de datos
  • Mismo modelo de roles en todas las apps (PA, ED, CO, GE)
📑

Registros y consultas

Opera sobre tus datos como en una hoja de cálculo: listado paginado, filtros por campo, búsqueda y ordenamiento.

  • CRUD completo con soft delete
  • Tabla editable tipo hoja de cálculo en el navegador
  • Filtros y búsqueda por tipo de campo
  • Exportación a hoja de cálculo (roadmap)
🔐

Usuarios y permisos

Control de acceso en dos niveles: tipo de usuario global (UA, US, UF) y roles por proyecto (PA, ED, CO, GE).

  • Autorización de miembros por proyecto
  • Roles: admin, editor, consulta, generar
  • Aislamiento por compañía (multi-tenant)
  • Alta administrada — sin registro público
🔍

Auditoría e historial

Responde quién creó o modificó cada registro y qué valor cambió. Trazabilidad completa para equipos operativos.

  • Historial por registro y por campo
  • Metadatos: usuario, fecha, valor anterior
  • Visible para administradores de proyecto
  • Integridad referencial con UUID
📊

Importación desde hoja de cálculo

Acelera la adopción migrando hojas existentes. El sistema analiza columnas y propone la estructura de campos.

  • Análisis automático de columnas
  • Creación de campos sugeridos
  • Carga masiva de registros
  • Reporte de errores por fila
🛡️

Seguridad y licencias

Acceso protegido con correo verificado y 2FA. Cada compañía opera bajo su propia suscripción y plan.

  • Verificación por correo en primer acceso
  • Autenticación TOTP (autenticador)
  • Planes Basic, Pro y Enterprise
  • Suscripción vigente requerida para operar

Suite de aplicaciones

Seis productos sobre el mismo chasis. Elige según el problema: tablas de equipo o ciclo de archivos.

WS

Worksheets

Tablas configurables con campos dinámicos, registros, permisos y auditoría — reemplazo de hojas operativas.

  • Esquema por proyecto sin desarrollo
  • Membresías y roles PA / ED / CO / GE
  • Vista expandida y apariencia
FP

FilePipe

Data Mapping: transforma archivos (TXT posicional, CSV, Excel y similares) con mapeo, reglas y versiones publicadas.

  • Origen → destino → mapeo → reglas
  • Ejecución con preview e historial
  • Catálogos reutilizables
FG

File Gate

Validador de archivos: comprueba conformidad frente a un contrato publicado y genera informe de aceptación o rechazos.

  • Esquema y políticas versionables
  • Corridas con content hash
  • Bridge opcional hacia FilePipe / Reverse / Match
RS

Reverse Studio

Emisor de layouts: de planilla (CSV/Excel) a archivo de envío posicional, JSON o XML según definición publicada.

  • Perfil de entrada y layout de salida
  • Generación controlada por versión
  • Pre-check opcional con File Gate
FM

File Match

Conciliador A vs B: cruza dos archivos por clave, aplica reglas de comparación y reporta diferencias.

  • Perfiles A y B independientes
  • Claves, normalización y comparación
  • Informe e historial de conciliaciones
SS

Structure Scout

Explorador de estructura: sube una muestra, detecta patrón/campos y acelera el modelado hacia Gate o Reverse.

  • Detección asistida desde muestra
  • Propuesta de campos y borrador
  • Aplicación a proyectos destino
