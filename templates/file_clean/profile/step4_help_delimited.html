Ayuda — Campos delimitados (CSV / TXT)

Explica los parámetros del delimitador y cada campo del editor. Tipo actual: {{ file_type_code|default:"csv" }}.

← Volver al paso 4

Parámetros del archivo

Campo en pantallaPara qué sirve
Delimitador Carácter que separa columnas: coma ,, punto y coma ;, tabulador o pipe |. Debe coincidir con el archivo real.
Carácter de comillas Envuelve valores que contienen el delimitador (normalmente "). Ejemplo: "Calle Sol, 12".
Carácter de escape Opcional. Escapa comillas dentro del valor (p. ej. \). Déjelo vacío si el archivo no lo usa.
Primera fila es encabezado Si está marcado, la fila de nombres de columna no es un registro de datos. Sirve para mapear por nombre de columna.
Fila encabezado Número de fila (1-based) donde están los títulos. Suele ser 1. Visible cuando hay encabezado.

Editor de cada campo

Campo en pantallaPara qué sirve
Columna del archivo Nombre del encabezado en el CSV (ej. DOC_ID). Útil si «Primera fila es encabezado» está activo. Es una etiqueta de referencia; el parseo usa el índice.
Nombre interno * Identificador estable del campo en Clean (telefono, edad). Lo usan las reglas y el archivo limpio. Minúsculas, sin espacios raros.
Índice (0-based) * Posición de la columna empezando en 0. Primera columna = 0, segunda = 1, etc. Ejemplo: en nombre,edad,direccion, edad es índice 1. Es el dato que el parser usa siempre para extraer el valor.
Tipo contenido Clasificación del valor (texto, numérico, fecha, custom…). En Ejecutar Clean no rechaza filas por este tipo; sirve de documentación y para Gate si valida después.
Campo obligatorio Marca el campo como requerido en el perfil. Clean no bloquea la limpieza por vacío; Gate sí puede usarlo al validar.
Patrón regex (custom) Aparece si el tipo es custom. Expresión regular que describe la forma esperada del valor (ej. ^[A-Z0-9]+$). Obligatoria al guardar un campo custom.
Formato fecha Aparece si el tipo es fecha/datetime. Indica cómo interpretar el texto (ej. DD/MM/YYYY).

Ejemplo rápido

Archivo:

nombre,edad,direccion
Beatriz Martinez,19,Calle Parque 282
  • Delimitador: coma · Encabezado: sí · Fila encabezado: 1
  • Campo nombre → índice 0
  • Campo edad → índice 1
  • Campo direccion → índice 2

Relación con captura (pasos 2–3)

El inicio/fin de captura define qué filas se leen. El delimitador e índices definen cómo se parten esas filas en columnas. No confunda «fila encabezado = 1» con «inicio de captura = línea 2» si la línea 1 ya es un dato.
