File Clean · Módulo 2 · paso 2 · capture_start

Ayuda — Inicio de captura

Define desde qué punto empiezan las filas a limpiar. Todo lo anterior se omite: no entra a reglas ni al archivo de salida.

← Volver al paso 2 Resumen

Para qué sirve

Un archivo de proveedor casi nunca es “solo datos”. Suele traer título, membrete o líneas de control antes del detalle. Si el inicio está mal, File Clean trata esa basura como registros: las reglas reescriben basura y el archivo limpio (y las métricas) salen distorsionados.

Este paso guarda capture_start en el borrador. Ejecutar usa la versión publicada. La unidad es líneas (1 = primera línea); en Excel, el análogo son filas de hoja.

Qué entra y qué se ignora

Zona del archivoEfecto en la limpieza
Antes del inicio Se omite. No se limpia ni se escribe en la salida.
Desde el inicio hasta el fin (paso 3) Cada registro se parsea, se aplican las reglas y se escribe (salvo vista previa).
Después del fin Lo define el paso 3. Aquí solo fija el arranque.

Modos de inicio

Elija el modo del archivo real. Los parámetros aparecen según el modo.

ModoCuándo usarloCómo arranca
Primera línea
first		 Puro detalle: nada que saltar. Línea 1 inclusive.
Línea específica
line_number		 Cabecera con siempre las mismas líneas. La línea indicada (1-based) inclusive.
Tras N líneas iniciales
after_header_block		 Quiere “saltar N”, no “empezar en la N”. Con skip_lines = 3 la primera fila leída es la 4.
Marcador de inicio
marker_start		 Texto fijo que anuncia el detalle. La línea siguiente a la primera que contiene el texto. El marcador no se limpia.
Tras patrón regex
after_pattern		 El anuncio varía pero encaja en una expresión. La línea siguiente a la primera coincidencia.
Tras líneas en blanco
after_blank_run		 El detalle empieza después de un hueco vacío. Tras N líneas consecutivas vacías; arranca en la inmediata siguiente.

CSV / Excel y encabezado

En CSV o Excel con fila de nombres, el has_header / fila de header se configura en el paso 4. El paso 2 decide desde qué línea o fila empiezan los datos; no sustituye esa opción. Si el archivo es solo datos y pone línea 2, perderá el primer registro.

Coherencia con el paso 3

El fin debe quedar después de este inicio, en la misma unidad. Con EOF se lee desde aquí hasta el final.

Si el archivo no encaja

  • Línea de inicio más allá del archivo → no hay filas; Ejecutar avisa que no se obtuvo ninguna fila válida.
  • No aparece el marcador ni el patrón → no avanza el inicio: se mezcla el encabezado con el detalle.
  • Mida el archivo real del proveedor, no un ejemplo de laboratorio.

Roles

Solo PA y ED guardan. El resto ve el paso en solo lectura.
