File Clean · Módulo 2 · CleanProfile

Ayuda — Perfil de lectura

Hub del asistente: indicadores, importar estructura y los 4 pasos para parsear el archivo a limpiar.

← Volver al perfil Hub proyecto

Para qué sirve

El perfil describe cómo se lee el archivo: tipo, encoding, captura y campos. Reutiliza el mismo motor SourceProfile que FilePipe y FILE GATE, pero aquí el foco es la lectura para limpiar, no un contrato de validación ni un mapeo a destino de negocio.

Se edita siempre el borrador. Ejecutar usa solo la versión publicada (módulo 4), congelada junto con las reglas. Al ejecutar, File Clean no rechaza filas por content_type; el layout (tipo, captura, campos) sí debe coincidir.

  • Los nombres internos de campo alimentan las reglas (field_name, tokens {field:X}).
  • Si renombra o borra un campo, revise las reglas huérfanas antes de publicar.

Asistente (4 pasos)

PasoQué configura
1 · TipoFormato, encoding y fin de línea. Condiciona el paso 4 y las extensiones al Ejecutar.
2 · InicioDesde dónde empiezan los datos útiles (salta títulos y cabeceras).
3 · FinDónde deja de leer (EOF, línea, patrón, tope de filas…).
4 · CamposEstructura: posiciones, columnas, hoja, rutas JSON/XML. También tiene CTA de importar.

Orden recomendado

  1. Opcional: Importar estructura desde otra app (misma compañía, origen publicado o borrador Scout).
  2. Complete o revise los 4 pasos y guarde en cada uno.
  3. Defina Reglas con los nombres de campo del perfil.
  4. Publicar antes de Ejecutar. Un clic en Publicar con Perfil o Reglas incompletos avisa y no congela.

Roles

RolEn este hub
PA / EDEditan el borrador e importan estructura.
GE / COConsultan el hub y el historial de importaciones. No guardan el perfil.

Qué no hace este hub

  • No publica la versión (eso es Publicar).
  • No define reglas de limpieza (módulo Reglas).
  • No sube ni limpia un archivo (eso es Ejecutar).
  • No valida umbrales FILE GATE ni mapea a FilePipe.
  • Importar no publica ni copia reglas.
