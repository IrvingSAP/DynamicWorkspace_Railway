Ayuda — Ejecutar limpieza

Suba un archivo: se lee con el perfil publicado y se aplican las reglas publicadas. Opcional: vista previa.

← Volver a Ejecutar Publicar

Para qué sirve

Es el punto de partida para limpiar un archivo de producción. Usa solo la versión publicada (perfil + reglas congelados), no el borrador que esté editando ahora. No valida un contrato FILE GATE ni mapea a un destino FilePipe.

Si el hub está bloqueado

Qué veQué significa
Publique una versión antes de limpiar No hay versión activa. Complete Perfil y Reglas y publique. Solo se ejecuta lo congelado (FC1).
No tiene permiso para ejecutar… Su rol no es PA, ED ni GE (p. ej. CO). Puede consultar historial y resultados; no subir archivos.

Qué ve cuando puede ejecutar

ElementoSignificado
Versión activa / tipo / campos / reglas ON Snapshot publicado que se aplicará a este archivo, no el borrador.
Archivo de esta corrida Un archivo. Tamaño máximo y extensiones según el tipo publicado.
Vista previa Primeras filas (muestra) antes/después. Job dry_run: no hay archivo limpio ni logs descargables.
Ejecutar limpieza Job completo: guarda entrada, salida, change_log y métricas. Abre el resultado.
Corridas recientes Atajo al resultado de jobs recientes. El listado filtrable está en Historial.

Vista previa vs ejecución

AcciónQué haceArtifacts
Vista previa Lee una muestra, aplica reglas, muestra tablas Antes/Después. No. TTL de descargas no aplica (N/A en historial).
Ejecutar limpieza Procesa el archivo entero (salvo captura inicio/fin). Sí: limpio + log JSON/CSV. Caducan a los {{ ttl_days }} días.

Reglas en runtime

  • Solo reglas habilitadas de la versión activa, en el orden publicado.
  • replace_map: coincidencia exacta del valor completo; si no hay clave, el valor queda igual.
  • replace: fragmento dentro del texto. Sin regex en MVP.
  • compose / {seq}: contador por job; se reinicia en cada corrida (también en preview, desde seq_start).
  • File Clean no rechaza filas por tipo de contenido; si el layout no coincide (delimitador, captura), puede no leer filas.

Si el archivo no encaja

  • Extensión distinta al tipo publicado → error al subir.
  • Delimitador del perfil distinto al del CSV → cero filas; cambie el paso 4, publique de nuevo y reintente.
  • Captura inicio/fin mal puesta → basura en la salida o ninguna fila.

Roles

RolEn Ejecutar
PA / ED / GESuben archivo, vista previa, ejecución y descargas (si el TTL está vigente).
CONo ejecuta. Puede ver metadatos en historial/detalle, no contenido.

Qué no hace este módulo

  • No edita perfil ni reglas ni publica (use esos módulos).
  • No es el historial filtrable ni el detalle de auditoría de una corrida antigua.
  • No es FILE GATE (no hay veredicto passed/failed de contrato).
