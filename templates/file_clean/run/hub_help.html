Cómo correr un job con la versión publicada y qué obtiene de salida.

← Ejecutar

Qué es

Sube un archivo de producción, lo lee con el perfil publicado y aplica las reglas publicadas en orden. Genera archivo limpio + log de cambios.

Vista previa vs ejecución

AcciónQué hace
Vista previaPrimeras filas antes/después. No guarda salida definitiva (dry_run).
Ejecutar limpiezaJob completo: input + output + change_log + métricas.

Roles

PA, ED y GE pueden ejecutar y descargar. CO no ejecuta.

Reglas en runtime

  • Solo reglas habilitadas de la versión activa.
  • replace_map: match exacto del valor completo; sin match → intacto.
  • compose / {seq}: contador por job, reinicia en cada corrida.
