Ayuda — Miembros y permisos

Quién puede ver y trabajar en este proyecto de limpieza y qué hace cada rol. Solo el administrador (PA) abre esta pantalla.

← Volver a miembros Hub

Para qué sirve

Invite usuarios UF de {{ company.name_short }}. La membresía es la misma ficha (ProjectMembership) que Worksheets / FilePipe / FILE GATE; el rol decide qué pueden hacer en FILE CLEAN.

Un proyecto público se ve en el listado de la compañía sin ser miembro (consulta). Editar perfil, publicar o ejecutar siguen exigiendo membresía activa y el rol adecuado.

Flujo recomendado

  1. En privado, invite al menos un ED (diseño de reglas) y un GE (corridas operativas) antes de operar.
  2. Elija usuario y rol → Autorizar miembro.
  3. Si alguien ya estuvo y está inactivo, use Reactivar (no vuelve al desplegable de alta).
  4. El rol no sustituye publicar: ejecutar usa la versión activa, no el borrador.

Roles en FILE CLEAN

CódigoNombrePermisos principales
PAAdminMiembros, editar perfil y reglas, publicar, ejecutar, historial.
EDEditorEditar perfil y reglas; publicar; ejecutar. No gestiona miembros.
GEEjecutarEjecutar limpieza y descargar salida / log. No edita la definición ni publica.
CGConsulta-GenerarConsulta + ejecutar (CO + GE).
COConsultaHub e historial (metadatos); sin descarga de filas de negocio.

Qué no hace esta pantalla

  • No cambia la visibilidad público/privado del proyecto.
  • No publica la definición ni ejecuta limpiezas.
  • No invita usuarios de otra compañía ni cuentas que no sean UF.
