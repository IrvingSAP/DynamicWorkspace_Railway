Proyectos de normalización de su compañía: qué ve, qué significan las columnas y cómo empezar.

← Volver al listado + Nuevo proyecto

Qué es este listado

Es la puerta de entrada a FILE CLEAN (Limpieza). Cada fila es un proyecto con un perfil de lectura y reglas explícitas (trim, mapas, reemplazos…): entrega un archivo limpio y un log de cambios. No valida un contrato de producción (FILE GATE) ni mapea a un destino de negocio (FilePipe).

  • Solo se listan proyectos de su compañía (alcance UF).
  • Aparecen los proyectos donde usted es miembro y los públicos de la compañía (aunque no sea miembro).
  • Desde aquí crea un proyecto nuevo o abre el hub de uno existente.

El filtro de Visibilidad en la barra de la tabla permite restringir a públicos o privados. La tabla admite búsqueda y paginación.

Visibilidad y acceso

  • Privado: solo la membresía activa puede ver y trabajar según el rol.
  • Público: UF de la misma compañía pueden ver el proyecto sin ser miembros (consulta). Editar, publicar o ejecutar siguen exigiendo el rol adecuado.
  • El creador queda siempre como PA, independientemente de la visibilidad.

Roles (resumen)

RolPermisos principales
PAAdmin: miembros, perfil, reglas, publicar y ejecutar.
EDEditar perfil y reglas; publicar; ejecutar.
GEEjecutar y descargar artefactos (sin editar la definición).
COConsulta: ver hub e historial; sin descargas de filas de negocio.

Los miembros se gestionan dentro de cada proyecto (hub → Miembros, solo PA).

Cómo empezar

  1. Pulse + Nuevo proyecto (nombre, código/slug y visibilidad).
  2. En el hub, complete el perfil de lectura y las reglas.
  3. Opcional: Importar estructura (PROFILE_SEED) al perfil; no clona el catálogo de reglas.
  4. Publique una versión. Ejecutar usa solo la versión publicada.
  5. Ejecute un archivo; revise salida, log de cambios e historial.

Regla de producto: no se limpia producción contra un borrador. Guía completa: menú FILE CLEAN → Ayuda.

Qué no es este listado

  • No muestra proyectos de FILE GATE, FilePipe, FILE MATCH ni STRUCTURE SCOUT.
  • No edita el perfil ni las reglas (eso ocurre en el hub de cada proyecto).
  • No ejecuta limpiezas ni sube archivos de producción.
  • No valida contratos ni emite layouts: solo limpia y normaliza.
