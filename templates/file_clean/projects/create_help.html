Para qué sirve

Crea un proyecto FILE CLEAN: un espacio para definir un perfil de lectura y reglas explícitas (trim, mapas de códigos, reemplazos, plantillas…) y luego ejecutar una limpieza que entrega archivo limpio + log de cambios.

Quien crea queda como administrador (PA). El alta no sube archivo ni aplica reglas: el siguiente paso es el hub → Perfil de lectura. No es un validador (FILE GATE) ni un mapeo a destino de negocio (FilePipe).

Campos de esta pantalla

CampoQué hace
Nombre corto (código) Slug único en la organización (compartido con Worksheets, FilePipe y el resto de apps). Use minúsculas y guiones; no se puede reutilizar un código ya tomado.
Nombre visible Título que verá el equipo en el listado y el hub (p. ej. «Limpieza nómina mensual»).
Descripción Opcional. Contexto del archivo de origen, periodo o qué espera normalizar.
Privado Solo miembros explícitos ven y trabajan el proyecto (según rol). Tras crear, PA agrega miembros.
Público Los UF de la compañía pueden ver el proyecto. Editar perfil, publicar o ejecutar siguen exigiendo membresía y rol.

Acciones

  • Crear y continuar — da de alta el proyecto y abre el hub.
  • Cancelar — vuelve al listado sin guardar.

Qué hacer después

  1. (PA) Invite miembros si otras personas deben editar o ejecutar.
  2. Complete el perfil de lectura (tipo de archivo, captura, campos).
  3. Defina las reglas y el orden de aplicación.
  4. Publique una versión. Ejecutar usa solo la publicada, no el borrador.
  5. Ejecute un archivo de producción; revise salida, log e historial.

Qué no hace este formulario

  • No define el perfil ni las reglas de limpieza.
  • No valida un contrato GATE ni transforma a un layout FilePipe.
  • No clona un perfil ya publicado (eso es Importar estructura / Profile Seed, en el perfil).
  • No sube ni limpia un archivo de producción.
