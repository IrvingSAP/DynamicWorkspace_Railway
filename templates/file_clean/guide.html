Cómo funciona File Clean

File Clean limpia y normaliza archivos con reglas explícitas (trim, mapas de códigos, find/replace, plantillas…) antes de validar o transformar.

No valida contratos de producción (eso es File Gate). No mapea a un destino de negocio (eso es FilePipe). Entrega un archivo limpio + log de cambios.

Ruta rápida

  1. Cree un proyecto File Clean.
  2. Defina el perfil de lectura.
  3. Ordene las reglas de limpieza.
  4. Publique una versión.
  5. Ejecute (preview o job) y descargue salida + log.
  6. Consulte el historial de jobs.

Ir a proyectos

Los 5 pasos del ciclo

  1. Perfil — Cómo se lee el archivo (tipo, encoding, campos).
  2. Reglas — Catálogo ordenado; nada se limpia si no hay regla.
  3. Publicar — Congela perfil + reglas; validación P5 de params.
  4. Ejecutar — Solo versión publicada; output + change log.
  5. Historial — Jobs, hashes, artifacts.

Disponibles: ciclo de proyecto, perfil, reglas y publicar. Ejecutar e historial llegan en entregas siguientes.
