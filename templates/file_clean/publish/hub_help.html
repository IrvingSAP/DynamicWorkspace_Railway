Ayuda — Publicar versión

Congela perfil de lectura y reglas. Ejecutar usa solo esa versión activa.

← Volver a publicar Hub proyecto

Para qué sirve

Publicar toma el borrador (perfil + reglas) y lo deja inmutable como versión vN. A partir de ahí, Ejecutar e Historial usan solo esa versión activa (FC1), no lo que siga editando en el borrador.

Tras publicar se crea un nuevo borrador (copia) para seguir editando. Los jobs que ya estaban en curso siguen con la versión con la que arrancaron (P4).

Qué ve en esta pantalla

ElementoSignificado
Publicar vN PA/ED. Pide confirmación y congela el borrador. Si Perfil o Reglas no están listos, el botón sigue siendo clicable y muestra una alerta (no queda inerte).
Franja de versión Qué número se va a publicar y cuál es la versión activa (la que usa Ejecutar). Si aún no hay, verá «Sin versión publicada».
Pendiente Aviso si falta el perfil, las reglas o ambos. Complete el checklist.
Reglas inválidas (P5) Reglas habilitadas con parámetros incompletos (p. ej. replace sin find). Corríjalas en Reglas antes de publicar.
Checklist Tarjetas a Perfil y Reglas: Listo o Pendiente, con un detalle (campos, reglas ON, etc.).
Resumen del borrador Tipo, encoding, cantidad de campos y reglas habilitadas (y cuántas están OFF).
Historial de versiones vN, estado (borrador / publicada), fecha y quién publicó.
Ir a Ejecutar Solo si ya hay una versión publicada.

Requisitos para publicar

CódigoQué exige
P1 · Perfil Al menos un campo en el perfil de lectura (los 4 pasos del wizard coherentes).
P2 · Reglas Al menos una regla habilitada. Las desactivadas no cuentan.
P5 · Params Toda regla ON debe tener parámetros válidos (replace_map, replace, compose, etc.).

Si pulsa Publicar sin completar Perfil y Reglas, el mensaje es: «Complete los pasos anteriores (Perfil y Reglas) antes de publicar.» (o el paso concreto que falte).

Roles

RolEn este hub
PA / EDVen el botón Publicar y pueden congelar el borrador.
GE / COConsultan checklist, resumen e historial de versiones. No publican.

Qué no hace este módulo

  • No edita el perfil ni las reglas (use esos módulos y vuelva a publicar).
  • No sube ni limpia un archivo (eso es Ejecutar, y exige versión publicada).
  • No valida un contrato FILE GATE ni mapea a FilePipe.
  • No sustituye Importar estructura: el seed deja borrador; aquí se congela.
