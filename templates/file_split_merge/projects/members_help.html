Ayuda — Miembros

Quién puede ver, editar, publicar o ejecutar en este proyecto. Solo el administrador (PA) gestiona el acceso.

← Miembros Hub

Quién gestiona

Solo el PA de {{ project.slug }} puede invitar, cambiar rol, reactivar o revocar. Si un no-PA abre esta URL, se redirige al hub con aviso de denegación.

Acciones

  • Invitar — usuario UF de la misma compañía + rol inicial.
  • Cambiar rol — PA, ED, GE, CG o CO.
  • Revocar / reactivar — membresía inactiva deja de contar como acceso de miembro.

Roles en File Split/Merge

RolPuede
PA Administrar miembros; editar perfil/reglas; publicar; ejecutar; ver historial.
ED Editar borrador, publicar y ejecutar; no gestiona miembros.
GE Ejecutar y descargar artifacts; no edita definición ni publica.
CG Consulta del proyecto y ejecutar / descargar (CO + GE).
CO Consulta de metadatos (hub, historial); sin descarga de contenido ni edición.

Si el proyecto es público (visibilidad compañía), otros UF pueden ver el hub sin ser miembros; eso no sustituye una membresía para editar o ejecutar.

Propietario

El propietario del proyecto no se revoca ni cambia de rol desde esta pantalla. Es la ancla de administración del contenedor.

Qué no hace

  • No cambia la visibilidad Privado/Público (eso se define al crear / config del proyecto).
  • No publica versiones ni ejecuta jobs.
  • No invita usuarios de otra compañía.
