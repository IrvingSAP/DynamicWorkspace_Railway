Alcance

Este hub es el punto de entrada de {{ project.slug }}. Agrupa perfil, reglas Split/Merge, versión publicada, ejecuciones e historial de este proyecto. No es File Gate, FilePipe, File Match ni File Clean.

Orden del ciclo

#MóduloQué hace
1PerfilCómo se lee el archivo (tipo, captura, campos).
2ReglasOperación Split o Merge + catálogo de reglas del borrador.
3PublicarCongela perfil + operación + reglas en una versión inmutable.
4EjecutarUpload y artifacts (solo versión publicada activa · SM1).
5HistorialAuditoría de jobs de este proyecto; descargas con TTL.

El stepper del hub marca avance (completado / pendiente / bloqueado). Reglas exige perfil completo; Ejecutar exige versión publicada.

Strip de resumen

  • Borrador vs versión activa publicada.
  • Operación actual del borrador (Split / Merge / sin definir).
  • Último job y conteo de miembros.

Split vs Merge

  • Split: 1 archivo → N partes + manifiesto + ZIP.
  • Merge: ≥2 archivos → 1 consolidado.
  • Una sola operación por borrador; se elige en Reglas, no aquí.

Miembros

El botón Miembros solo lo ve el administrador (PA). Invitar, cambiar rol o revocar se hace en esa pantalla.

Roles (resumen)

RolEn este proyecto
PATodo: miembros, edición, publicar, ejecutar.

Qué no hace el hub

  • No edita campos ni reglas directamente (use los módulos).
  • No mezcla jobs de otros proyectos: el historial es por slug.
  • No limpia, concilia ni mapea a destino de negocio.
