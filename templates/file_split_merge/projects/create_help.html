Ayuda — Nuevo proyecto

Alta del contenedor: perfil vacío, sin reglas ni versión publicada. Usted queda como administrador (PA).

← Nuevo proyecto

Quién puede crear

Solo usuarios UF con seguridad completa. Al crear: proyecto tipo File Split/Merge, configuración DMS y membresía PA del creador.

Campos

CampoNotas
NombreObligatorio. Título visible en listados y hub.
Código (slug) Obligatorio. Único por compañía entre todas las apps. Minúsculas y guiones (p. ej. prueba-03-xls).
DescripciónOpcional. Contexto para el equipo.
Visibilidad Privado (default): solo miembros. Público: UF de la compañía pueden ver el hub en consulta.

Qué no se elige aquí

  • La operación Split o Merge se define en Reglas (M3), no al crear.
  • Tipo de archivo y campos van en Perfil (M2).
  • No se publica ni se ejecuta en este paso.

Después de crear

  1. Redirección al hub del proyecto.
  2. Perfil → Reglas → Publicar → Ejecutar → Historial.
  3. Como PA puede invitar miembros desde el hub.

Recuerde: cada proyecto tiene su propio historial de jobs. Use un proyecto por escenario de prueba si quiere aislar CSV, TXT, XLSX, etc.
