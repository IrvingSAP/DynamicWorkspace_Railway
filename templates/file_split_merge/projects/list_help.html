Qué ve en el listado

Solo proyectos File Split/Merge de su compañía donde usted es miembro, o proyectos públicos (visibilidad compañía) aunque no sea miembro. No aparecen proyectos de File Gate, Clean, Match ni FilePipe.

El filtro de Visibilidad restringe a públicos o privados. La tabla admite búsqueda y paginación (mismo patrón que FILE GATE).

Split vs Merge

OperaciónIdea
Split1 archivo → N partes (filas, tamaño o valor de columna) + manifiesto.
Merge≥2 archivos → 1 consolidado.

La operación no se elige al crear el proyecto: se define en Reglas (módulo 3), después del perfil de lectura.

Historial y tipos de archivo

El historial de ejecuciones es por proyecto. Si probó CSV, TXT y XLSX en proyectos distintos, cada historial muestra solo las corridas de ese slug.

Qué no es

  • No valida contrato (File Gate) ni limpia celdas (File Clean).
  • No concilia (File Match) ni mapea a destino de negocio (FilePipe).
