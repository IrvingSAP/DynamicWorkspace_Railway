Alcance: un proyecto

El historial muestra solo las corridas de este proyecto ({{ project.slug }}. No es un listado global de la compañía ni se filtra por tipo de archivo (CSV, TXT, XLSX…).

Si ejecutó Split/Merge en varios proyectos (p. ej. uno por formato de prueba), cada historial vive en su propia URL: /app/file-split-merge/proyectos/<slug>/historial/. Abra el hub de cada proyecto para ver sus jobs.

Qué ve en el listado

  • Operación (Split / Merge), estado, versión publicada usada, usuario, fechas.
  • Nombre de archivo(s), hash y métricas resumidas.
  • Badge de TTL: artifacts descargables mientras estén vigentes ({{ ttl_days }} días).

Filtros

Estado, operación, fechas, usuario, nombre de archivo, hash, versión publicada, preview vs ejecución real, y TTL (vigente / expirado / todos). Paginación de 25 filas.

Detalle

  • Split — manifiesto de partes, conteos y ZIP si sigue disponible.
  • Merge — métricas de consolidación / dedupe y archivo fusionado.

Roles

RolPuede
PA / ED / GE Ver listado y detalle; descargar artifacts con TTL vigente; eliminar solo corridas que usted ejecutó.
CO Ver metadatos del historial; no descarga contenido ni elimina.

Borrado

Solo corridas propias (fila o «Eliminar mis corridas»). Al borrar se purga el almacenamiento del job; no se pueden borrar ejecuciones de otros miembros.

Qué no hace

  • No mezcla jobs de otros proyectos Split/Merge.
  • No filtra automáticamente por tipo de archivo del perfil; use el filtro de nombre si necesita localizar un CSV/TXT/XLSX concreto dentro de este proyecto.
  • Tras caducar el TTL, los metadatos permanecen; las descargas dejan de estar disponibles.
