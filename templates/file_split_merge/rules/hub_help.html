File Split/Merge · Módulo 3 · SmRules

Ayuda — Reglas Split / Merge

Defina la operación (partir o unir) y el catálogo de reglas del borrador. No limpia celdas ni concilia.

← Reglas

Alcance: este proyecto

Las reglas pertenecen al borrador de {{ project.slug }}. Hay una sola operación por borrador: Split o Merge. Primero complete el perfil de lectura (tipo, captura y ≥1 campo); sin eso el hub no permite configurar reglas.

Operación

ModoEntrada (en Ejecutar)Salida
Split (partir) 1 archivo N partes + manifiesto + ZIP
Merge (unir) ≥2 archivos 1 consolidado

Al cambiar de operación aparece un aviso: debe confirmar «Confirmar cambio y limpiar reglas». Se borran las reglas del modo anterior (no publica). En Merge, al elegir la operación se crea automáticamente missing_columns con modo error.

Catálogo Split

CódigoPara qué
max_rowsPartir cada N filas de datos.
max_bytesPartir por tamaño aproximado (corte en límite de fila).
split_by_columnUna parte por valor distinto de un campo del perfil.
keep_headerRepetir encabezado en cada parte (opcional; sola no completa).

Completitud Split: al menos una regla de partición ON entre max_rows, max_bytes o split_by_column. Puede activar varias a la vez; el motor las aplica en el orden de la lista.

Catálogo Merge

CódigoPara qué
missing_columnsSi falta una columna del perfil: error o fill_empty (requerida).
appendMarca explícita de concatenar (el merge siempre une filas en orden de subida).
dedupe_rowsDeduplicar tras unir por claves del perfil (opcional).
include_headerIncluir fila de encabezado en la salida (opcional).

Completitud Merge: operación Merge y missing_columns habilitada (se crea al elegir Merge si aún no existe).

Campos del perfil

split_by_column.field_name y dedupe_rows.keys usan nombres internos del perfil (M2), no etiquetas libres. Si renombra o elimina un campo, revise las reglas que lo referencian antes de publicar.

Guardar y publicar

  • Todo se guarda en el borrador (sm_rules); no congela versión.
  • Cuando la completitud diga «Lista», puede continuar a Publicar (M4) para congelar perfil + operación + reglas.
  • La ejecución (M5) usa solo la versión publicada activa, no este borrador.

Roles

RolPuede
PA / ED Elegir operación, agregar/editar/reordenar/activar reglas del borrador.
GE / CO Ver el hub; no editan el borrador de reglas.

Qué no hace

  • No define el perfil de lectura (M2) ni publica (M4) ni sube archivos (M5).
  • No limpia celdas (File Clean) ni concilia / mapea destino (File Match / FilePipe).
  • No permite Split y Merge activos a la vez en la misma versión.
