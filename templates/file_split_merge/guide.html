Cómo funciona File Split/Merge

File Split/Merge permite partir un archivo en varios (Split) o unir varios en uno (Merge), con reglas versionadas.

No concilia por clave (File Match). No limpia celdas (File Clean). No mapea a un destino de negocio (FilePipe).

Ruta rápida

  1. Cree un proyecto File Split/Merge.
  2. Defina el perfil de lectura.
  3. Elija Split o Merge y sus reglas.
  4. Publique una versión.
  5. Ejecute y descargue las salidas.
  6. Consulte el historial de jobs.
