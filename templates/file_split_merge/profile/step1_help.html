Tipo de archivo a partir o unir

Fija el formato, la codificación y el fin de línea con los que File Split/Merge interpretará cada archivo.

Qué decide este paso

Sin tipo de archivo no se puede completar el perfil ni publicar. La elección condiciona el paso 4 (posiciones, columnas, hoja, JSON o XML) y las extensiones permitidas al Ejecutar.

ElementoEfecto en File Split/Merge
Tipo de archivo Formato esperado (txt_fixed, csv, txt_delimited, xlsx, json, xml). Condiciona el parseo al procesar.
Encoding Cómo se leen los bytes. Un encoding incorrecto suele producir caracteres raros o basura en los campos.
Fin de línea Cómo se parten las líneas (LF, CRLF o auto). Debe coincidir con el archivo del proveedor.

Buenas prácticas

  • Elija el tipo que usa el proveedor; no “el más flexible”.
  • Si ya hay campos definidos y cambia el tipo, revise el paso 4: la estructura anterior puede quedar inválida.
  • Los cambios se guardan en el borrador; Ejecutar solo usa lo publicado.
  • Solo PA y ED pueden guardar. El resto ve el paso en solo lectura.
