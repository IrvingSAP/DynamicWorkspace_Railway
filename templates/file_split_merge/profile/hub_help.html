File Split/Merge · Módulo 2 · SmProfile

Ayuda — Perfil de lectura

Define cómo se parsea el archivo de entrada. Reutiliza SourceProfile (mismo parser que Pipe/Gate/Clean). No elige aquí Split vs Merge.

← Volver al perfil

Qué es

El perfil de lectura describe tipo, encoding, captura y campos del archivo de entrada. Se edita en borrador; al publicar (módulo 4) se congela junto con las reglas.

  • Los nombres internos alimentan M3 (split_by_column, claves de dedupe).
  • No incluye políticas Gate ni limpieza Clean: solo layout de lectura compartido por Split y Merge.
  • Al ejecutar, File Split/Merge no rechaza filas por content_type (soft-parse); el layout sí debe coincidir.

Wizard (4 pasos)

#PasoQué define
1TipoFormato, encoding y fin de línea.
2InicioDesde qué línea / patrón empiezan los datos útiles.
3FinDónde deja de leer (EOF, línea, patrón…).
4CamposEstructura: posiciones, columnas, hoja, rutas JSON/XML.

Orden recomendado

  1. Complete los 4 pasos del perfil.
  2. Defina reglas (módulo 3) usando los nombres de campo.
  3. Publique (módulo 4) antes de Ejecutar.

Si renombra o borra un campo, revise las reglas que lo referencian antes de publicar.

Roles

PA y ED editan el borrador. GE / CO pueden consultar según membresía, sin guardar.

Qué no hace este hub

  • No publica la versión (eso es Publicar).
  • No sube archivos de producción (eso es Ejecutar).
  • No define reglas Split/Merge (módulo Reglas).
