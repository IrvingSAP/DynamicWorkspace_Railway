Ayuda — Perfil de lectura

Hub del perfil: indicadores, importar estructura y los 4 pasos del asistente. Aquí no se elige Split vs Merge.

← Volver al perfil

Propósito

El perfil describe cómo se lee el archivo en {{ project.name }}: tipo, encoding, captura y campos. El mismo layout sirve para Split (1→N) y Merge (N→1). No valida contrato (File Gate), no limpia celdas (File Clean) y no mapea a destino (FilePipe).

Se edita siempre el borrador. Ejecutar usa solo la versión publicada (módulo 4), congelada junto con las reglas. File Split/Merge no rechaza filas por content_type (soft-parse); el layout sí debe coincidir.

Flujo recomendado

  1. Opcional: Importar estructura (solo PA/ED) para no rearmar el asistente.
  2. Complete o revise los 4 pasos del perfil y guarde en cada uno.
  3. Defina Reglas (módulo 3) usando los nombres internos de campo (split_by_column, claves de dedupe, etc.).
  4. Publique (módulo 4) antes de Ejecutar.

Si renombra o borra un campo, revise las reglas que lo referencian antes de publicar.

Indicadores

IndicadorQué muestra
Pasos completosCuántos de los 4 pasos tienen lo mínimo para avanzar.
Tipo archivoFormato del paso 1 (posicional, CSV/delimitado, Excel, JSON, XML, …).

La etiqueta de borrador y la versión publicada aparecen en la franja del proyecto (hub) y al publicar, no en estas tres tarjetas.

Orígenes al importar

Misma compañía y proyectos que usted puede ver. El destino queda en borrador. Este mismo proyecto Split/Merge no aparece como origen. Salvo Scout, el origen debe estar publicado.

Si el tipo de archivo no es compatible con Split/Merge, la confirmación rechaza la siembra y no escribe el borrador.

Asistente (4 pasos)

PasoQué configura
1 · TipoFormato, encoding y fin de línea del archivo a partir o unir.
2 · InicioDesde dónde empiezan los datos útiles (salta cabeceras o títulos).
3 · FinDónde deja de leer (EOF, línea o patrón).
4 · CamposEstructura: posiciones, columnas, hoja, rutas JSON/XML. Los nombres internos alimentan las reglas. También hay CTA de importar.

Cambiar el tipo de archivo con campos ya definidos puede exigir limpiar o redefinir el paso 4.

Qué no hace este hub

  • No elige operación Split vs Merge ni define reglas (eso es Reglas).
  • No publica la versión (eso es Publicar).
  • No sube archivos de producción (eso es Ejecutar).
  • No es File Gate (contrato/políticas), File Clean (limpieza) ni FilePipe (mapeo).
  • No infiere desde una muestra aquí: Scout entra como origen del sembrador o desde Explorador con «Aplicar a destino».
  • Importar no publica Split/Merge ni sustituye las reglas.
