Inicio de captura

Indica desde qué punto del archivo empiezan los datos a procesar. Todo lo anterior (títulos, banners, metadatos) se ignora.

← Volver al paso 2

Para qué sirve

Muchos archivos traen cabeceras o líneas de control antes del detalle. Si el inicio está mal, Clean leerá basura como si fueran registros (o saltará filas de datos reales).

ElementoUso típico
Modo de inicio Primera línea, número de línea, tras un patrón / bloque de encabezado, etc.
Parámetros Valor del modo: número de línea, texto del patrón, líneas a saltar…

Casos frecuentes

  • Archivo solo de datos (sin encabezado): use primera línea o línea 1. Si pone línea 2, perderá el primer registro.
  • CSV con encabezado: el inicio de captura suele ser la primera fila de datos; el encabezado se configura también en el paso 4 (has_header / fila de header).
  • TXT fijo con título: número de línea posterior al título, o patrón que marca el inicio del detalle.

Coherencia con el paso 3

La unidad es líneas. El fin de captura no puede quedar “antes” del inicio. Con Excel, la lógica análoga usa filas de hoja.
