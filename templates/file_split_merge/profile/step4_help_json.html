Parámetros JSON

Campo en pantallaPara qué sirve
Ruta de registros (record_path) * Camino hasta el array (o objeto) que se repite por fila. Ejemplos: empleados, data.items. Cada elemento de esa lista es un registro a procesar.

Editor de cada campo

Campo en pantallaPara qué sirve
Nombre interno * Identificador en Clean / reglas.
json_path * Ruta relativa dentro de cada registro (notación con puntos). Si el registro es {"documento":"A1","persona":{"edad":19}}, use documento o persona.edad.
Tipo contenido Clasificación del valor. Clean no rechaza por content_type al ejecutar.
Campo obligatorio Marca de perfil; Gate puede usarlo después.
Patrón regex (custom) Aparece si el tipo es custom. Expresión regular de la forma esperada (ej. ^[A-Z0-9]+$). Obligatoria al guardar un campo custom.
