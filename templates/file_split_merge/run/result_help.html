Ayuda — Resultado

Estado, métricas y descargas de una corrida Split/Merge de este proyecto.

← Resultado Ejecutar

Alcance

El resultado pertenece al proyecto {{ project.slug }} y a un job concreto. Otras corridas (otros proyectos o formatos) se ven en su propio historial o en el del proyecto donde se ejecutaron.

Qué muestra

  • Estado — completado o fallido; si fue vista previa, queda marcado como preview.
  • Versión — número de la definición publicada usada (congelada al correr).
  • Métricas — filas leídas, partes o filas escritas, dedupe (Merge), duración.
  • Vista previa de datos — muestra de filas cuando la corrida lo permite.
  • Descargas — según operación, TTL y rol.

Descargas por operación

OperaciónArtifacts
Split ZIP (todas las partes + manifiesto) y, si aplica, partes individuales.
Merge Archivo consolidado (merged con la extensión del perfil).

La vista previa no genera archivos definitivos descargables. Use Ejecutar (no preview) cuando necesite el ZIP o el consolidado.

TTL

Las descargas están disponibles durante {{ ttl_days }} días desde la finalización. Después dejan de ofrecerse; el job y sus metadatos siguen en el historial del proyecto.

Roles

RolPuede
PA / ED / GE Ver resultado completo y descargar artifacts con TTL vigente.
CO Ver metadatos / métricas; no descarga contenido.

Siguientes pasos

  • Nueva corrida — vuelve a Ejecutar con la misma versión publicada.
  • Historial — auditoría, filtros y detalle a largo plazo (mismo proyecto).
  • Si el job falló, revise el mensaje de error, el archivo de entrada y que el perfil publicado coincida con el formato.

Qué no hace

  • No re-ejecuta ni cambia reglas; para eso use Ejecutar / Reglas / Publicar.
  • No mezcla resultados de otros proyectos.
  • No sustituye al historial: el resultado es la vista inmediata tras la corrida; el historial es la auditoría persistente.
