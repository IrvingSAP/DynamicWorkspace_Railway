Qué es este paso

Es el Módulo 1 de PROFILE SEED (Sembrador de perfiles). Confirma el destino de la siembra: este proyecto FILE MATCH · slot Perfil A. Aún no elige origen ni escribe el borrador.

  • Copy correcto: “Importar estructura”. No es “sincronizar”, “vincular”, “bridge” ni “aplicar Scout”.
  • Efecto futuro: solo borrador del Perfil A. La publicación Match sigue siendo el Módulo 4 del Conciliador.
  • Prioridad P0: origen típico FILE GATE (esquema publicado) → este Perfil A.

Flujo completo (3 pasos)

#PasoQué hace

3 Confirmar Preview, aviso si hay overwrite, y siembra el borrador A. Queda auditado en historial.

Qué hará a continuación

  1. Pulse Continuar a elegir origen (Módulo 2).
  2. Seleccione un origen publicado que pueda ver (misma compañía).
  3. Revise el preview y confirme (Módulo 3): se siembra el borrador; si ya había campos, verá aviso de overwrite.
  4. Revise o ajuste el Perfil A en el wizard de 6 pasos; publique Match cuando la definición esté lista.

Qué no hace este paso

  • No lista orígenes ni elige versión publicada (eso es Origen).
  • No muestra preview ni escribe el borrador (eso es Confirmar).
  • No publica la definición Match ni configura el bridge FILE GATE.
  • No abre STRUCTURE SCOUT ni sube una muestra.
  • No clona políticas GATE, reglas de cruce Match ni destino Reverse — solo la forma del origen/entrada.
